# وەشانی بنەڕەتی 0.20.0

## ئەوەی کار دەکات

- ڕێکخستنی یەکەمی خاوەن، چوونەژوورەوە و دەرچوونی ناوخۆ.
- چوار ڕۆڵ؛ پشکنینی دەسەڵات لە سێرڤەر، بەڕێوەبردنی کارمەند لەلایەن خاوەن و تۆماری گۆڕانکاریی دەسەڵات.
- دانیشتنی ١٢ کاتژمێری، قوفڵی هەوڵدانی زۆر و کۆتاییهێنان بە دانیشتن دوای گۆڕینی ڕۆڵ/چالاکی.

- دابینکەر: تۆمارکردن و دەستکاری بە ژمارەی وەشان، کۆدی یەکتا، گەڕان، پەڕەبەندی و پرۆفایلی زانیاری؛ تەنها ناوخۆیی.
- شاشەی قوفڵکراوی ٦ کارت و ناوبەری ١٥ بەش.
- کاڵا: ناو، کۆدی ناوخۆ، IQD/USD، نرخی دانە/کڕین/کارتۆن، دانەی کارتۆن، بڕی سەرەتایی و فرەبارکۆد.
- بارکۆد بە دەق پارێزراوە؛ سفرەکانی سەرەتا نامرن. هەر بارکۆدێک بە یەک کاڵا و یەک یەکە پەیوەستە.
- ڕاپۆرتی فرۆشتنی نەقد: کۆ و ژمارەی پسوولە بە جیا بۆ IQD/USD، فلتەری بەروار و ڕیزبەندی ڕۆژانە بۆ خاوەن/بەڕێوەبەر.
- کۆگا: هەناردەی CSV ـی هەموو کاڵاکانی فلتەر بەبێ نرخ/تێچوو، بڕی بەردەست، گەڕان، فلتەری سفر/بەردەست، مێژووی جووڵە و پشکنینی یەکگرتنەوەی بڕ لەگەڵ ledger.
- کاشێر: گەڕان، سکانی بارکۆد بە Enter، دانە/کارتۆن، بڕ، پارەی وەرگیراو و گەڕاوە.
- فرۆشتنی نەقد بە یەک دراو لە هەر پسوولە؛ نرخەکان لە داتابەیس دەخوێندرێنەوە.
- فرۆشتن، کەمکردنەوەی کۆگا، تۆماری کۆگا و outbox لە یەک transaction.
- ناسنامەی یەکتای داواکاری بۆ پاراستن لە فرۆشتنی دووبارە.
- پسوولە لەگەڵ چاپی وێبگەڕ؛ تاقیکردنەوەی پڕینتەری ڕاستەقینە هێشتا نەکراوە.
- لیست، داگرتن و پشکنینی سالمبوونی باکئەپ لە بەشی داتا، تەنها بۆ خاوەن؛ گەڕاندنەوەی ڕووکار هێشتا نییە.
- باکئەپی ناوخۆ هەر کاتژمێرێک تا سێرڤەرەکە کراوەیە؛ پاراستنی کۆتا ٢٤ وەشان.
- تاقیکردنەوەی گەڕاندنەوەی فایلە باکئەپەکان و SQLite integrity.

## بنەما

Node.js 24+، هیچ dependency ـی runtime پێویست نییە. SQLite لە Node هەیە.
`npm start` تەنها لە `127.0.0.1:3187` کار دەکات و پێویستی بە ئینتەرنێت نییە.
لە Linux داتای ڕاستەقینە لە `data/` ـە؛ لە Windows ـی نوێ لە `%LOCALAPPDATA%\ZHIROX-HyperMarket-OS\data` ـە. باکئەپ لە `backups/` ـی ناو فۆڵدەری داتایە. هەردووکیان لە Git دەرکراون.
`ZHIROX_DATA_DIR` شوێنی داتا دەگۆڕێت. بەکارهێنەر دەبێت فۆڵدەرەکە لەسەر دیسکی پارێزراو هەڵبژێرێت.
`npm run dev` تەنها بۆ QA ـی managed preview ـە و داتابەیسێکی کاتی جیا درووست دەکات.

## ماوە

ئەمە وەشانی بنەڕەتییە، ئامادەی کارکردنی ڕاستەقینەی مارکێت نییە.
بەشەکانی تر هێشتا پێشبینینی دیزاینن. قەرز، کڕین، گەڕاندنەوە، کشووی پارە،
تەرازووی بارکۆدی کێش، فرۆشتنی کێش بە بڕی کەرتی، installer ـی Windows و نوێکردنەوەی خۆکار هێشتا ماون.
بڕی سەرەتایی بە تا ٣ ژمارەی دوای خاڵ دەپارێزرێت؛ فرۆشتنی ئەم وەشانە دانە/کارتۆنی ژمارە تەواوە.
سەبەتە و پارەی وەرگیراو بۆ هەر هەژمارێک لە SQLite پاشەکەوت دەبن؛ دوای reload یان چوونەژوورەوە دەگەڕێنەوە. تەنها گۆڕانکاریی پشتڕاستکراوی سێرڤەر بە پارێزراو هەژمار دەکرێت.
هاوکاتکردنی یەک‌ئاراستەی Supabase جێبەجێ کراوە؛ چالاکبوونی هەر کۆمپیوتەرێک پێویستی بە ناسنامەی تایبەت هەیە. [وردەکاری](SYNC.md).
گەڕاندنەوە لە کلاود و هاوکاتکردنی فرەئامێر هێشتا نەکراون؛ هاوکاتکردن جێگرەوەی باکئەپی SQLite نییە.

## پشکنین

- `npm test`: ١٥٧ تاقیکردنەوەی دەسەڵات، دانیشتن، CSRF و HTTP، transaction، بارکۆدی دووبارە، کۆگای ناکافی، پارەی کەم، دراو، idempotency، ledger و backup/restore.
- `npm run check`: syntax و پشکنینی دیزاینی قوفڵکراو.
- Browser QA لە داتابەیسێکی کاتی: کاڵا بە ٢ بارکۆدی دانە و ١ بارکۆدی کارتۆن تۆمار کرا؛
  کارتۆنێکی ٦ دانەیی بە ٨٠٠٠ دینار فرۆشرا، ١٠٠٠٠ دینار وەرگیرا، ٢٠٠٠ گەڕایەوە، کۆگا لە ٢٠ بۆ ١٤ دابەزی.
- Linux/Node 24 تاقی کراوەتەوە؛ Windows و ئامێرە ڕاستەقینەکان هێشتا پێویستیان بە تاقیکردنەوە هەیە.

## قۆناغی کڕین (0.21.0 — لە ژێر کاردا)

بەشی «کڕین»ی ڕووکاری قوفڵکراو بە GET ـی دابینکەر/کاڵا و POST /api/purchases/preview پەیوەست بوو. ئەم API ـە بۆ خاوەن/بەڕێوەبەرە و کۆی کڕین، بڕی دانە/کارتۆن، دراو و بڕی پێشبینیکراوی دوای وەرگرتن هەژمار دەکات. پێشبینینەکە تەنها خوێندنەوەیە؛ هیچ پارە، کڕین، ledger، کۆگا یان outbox ناگۆڕێت. تۆمارکردنی کڕین تا گەشەپێدانی sync ـی سەلامەت و تاقیکردنەوەی immutable ledger قوفڵە. [وردەکاری](PURCHASE_PREVIEW.md).

## قۆناغی داهاتوو

١. دەسەڵاتی وردتر بۆ کردارە داهاتووەکان و ڕێگای گەڕاندنەوەی دەستگەیشتن لە لەبیرچوونی وشەی نهێنی.
٢. دەستکاریی کاڵا بە مێژوو و کۆگا/گەڕاندنەوە.
٣. تاقیکردنەوە و ڕێکخستنی ناسنامە لە کۆمپیوتەری Windows ـی مارکێت.
٤. دامەزراندنی Windows، backup recovery UI، printer/scale/cash-drawer verification.
