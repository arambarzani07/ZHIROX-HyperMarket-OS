# بەڕێوەبردنی باکئەپ — 0.8.0

لە کارتی بەڕێوەبردن → داتا و باکئەپ، خاوەن دەتوانێت باکئەپی ئێستا دروست بکات، فایلە ناوخۆییەکان ببینێت، دایانبگرێت و پشکنینی سالمبوون ئەنجام بدات. دەسەڵاتی `backup.create` بۆ هەموو ئەم کردارە پێویستە؛ تەنها ڕۆڵی خاوەن هەیەتی و سێرڤەر پشتڕاستی دەکاتەوە.

## فایلەکان

باکئەپە خۆکارەکان هەر کاتژمێرێک دروست دەبن تا سێرڤەر کراوەیە. هەمان یاسای پاراستنی کۆتا ٢٤ فایل بۆ باکئەپی دەستی و خۆکار بەکاردێت. لیستەکە ناوی فایل، قەبارە بە بایت و کاتی دوا گۆڕان بە کاتی عێراق پیشان دەدات. فایلێک ڕەنگە لەنێوان لیست و داگرتندا بەهۆی یاسای پاراستن بسڕدرێتەوە؛ لەو دۆخەدا لیستەکە نوێ بکەرەوە.

فایلەکە کۆپێی SQLite ـە: کاڵا، فرۆشتن، سەبەتەکان، ledger، outbox، هەژمارەکان و hash ـی وشەی نهێنی/دانیشتن تێدایە. فایلەکە بەخۆی encryption نییە؛ لە شوێنی پارێزراو هەڵیبگرە. **ناسنامەی نهێنیی ئامێری کلاود (`sync-device.json`) لە SQLite نییە** و دەبێت بە جیا لە شوێنی پارێزراو هەڵبگیرێت؛ لە ئەم شاشەیە پیشان یان داگرتن ناکرێت.

## پشکنین

دوگمەی «پشکنین» کۆپێیەکی کاتیی تایبەت لە باکئەپ دروست دەکات. worker ـێکی جیا کۆپێکە بە read-only دەکاتەوە و ئەمانە دەپشکنێت:

- SQLite integrity check.
- بوونی خشتە/خانە بنەڕەتییەکانی پڕۆژە، لەگەڵ هەژمارەکان.
- Foreign key check بۆ پەیوەندیی تۆمارەکان.

لە سەرکەوتندا ژمارەی کاڵا، پسوولە و هەژمار لە وەڵامی API دەگەڕێندرێتەوە؛ ڕووکار ژمارەی کاڵا و پسوولە پیشان دەدات. وشەی نهێنی، hash، session یان payload ـی تایبەت لە وەڵامی پشکنین نییە.

تەنها یەک پشکنین لە هەر کاتێکدا ڕێگەپێدراوە. worker زۆرترین ٣٠ چرکە هەیە بۆ پشکنین، دوای کۆپیکردنی فایل. کۆپێی کاتی لە کۆتایی ئاساییدا پاک دەکرێتەوە. پشکنین فایلە باکئەپە سەرەکییەکە و داتابەیسی کارکردن ناگۆڕێت، و SQLite ـی کارکردن لە worker ناکرێتەوە.

«سالمە» پشتڕاستکردنەوەی ئەو سێ پشکنینەیە؛ بەڵگەی تۆماربوونی هەموو مامەڵە ڕاستەقینەکان، سازگاریی تەواوی هەموو وەشانەکان، یان ئامادەیی گەڕاندنەوە نییە. business reconciliation و ڕێڕەوی گەڕاندنەوەی داتا هێشتا جێبەجێ نەکراون.

## API و دەستگەیشتن

- `GET /api/backups`: ناوی فایل، bytes و modified_at؛ تەنها فایلە SQLite ـە ڕاستەقینەکان بە شێوازی ناوی ZHIROX.
- `GET /api/backups/:name/download`: داگرتنی باینەری بە attachment و no-store. فۆڵدەر، symlink، path traversal و فایلەکانی تری داتا ڕەت دەکرێنەوە.
- `POST /api/backups/:name/verify` لەگەڵ `{}` و CSRF: وەڵامی ok/reason، checked_at و count ـە سادەکان لە سەرکەوتندا.
- `POST /api/backup` هەر باکئەپی نوێ دروست دەکات.

داگرتن دانیشتنی چالاک پێویستە؛ manager، cashier و warehouse ڕەت دەکرێنەوە. ڕووکار وەڵامی داگرتنی کۆن کە دوای دەرچوون یان گۆڕینی دانیشتن تەواو بێت پشتگوێ دەخات. فایلێکی پێشتر داگیراو لە ئامێری بەکارهێنەر دەمێنێتەوە.

## پشکنین و ماوەکان

٤٩ تاقیکردنەوەی پڕۆژە تێپەڕین: باکئەپی سالم، فایلە خرابەکان، schema ـی نامۆ، foreign key ـی شکێنراو، ڕەتکردنەوەی symlink/path traversal، یەک پشکنین لە هەر کاتێک، پاککردنەوەی کۆپێی کاتی، مانەوەی SHA-256 ـی فایل پێش/دوای پشکنین، داگرتنی HTTP ـی byte-exact، دەسەڵات، CSRF، cross-origin و پشتگوێخستنی blob ـی دوای logout.

گەڕاندنەوە، هاوردەکردنی فایل، encrypted backup و گەڕاندنەوەی کلاود هێشتا نییە. پشکنینی بینراوی داگرتن و لیست لە وێبگەڕی چووەژوورەوە و Windows لەم قۆناغەدا ئەنجام نەدراوە. دیزاینی قوفڵکراو پارێزراوە.
