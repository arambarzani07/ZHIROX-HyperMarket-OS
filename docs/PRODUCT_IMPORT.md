# هاوردەکردنی کاڵا لە CSV — 0.15.0

ئەم ڕێڕەوە **کاڵای نوێ** زیاد دەکات. هیچ کاڵای هەبوو ناگۆڕێت، یەک ناخات و ناسڕێتەوە. دەسەڵاتی `products.write` پێویستە؛ خاوەن، بەڕێوەبەر و کارمەندی کۆگا هەیانە و کاشێر ڕەت دەکرێتەوە.

## کارپێکردن

١. لە بەشی کاڵاکان، «هاوردەی CSV» بکەرەوە.
٢. فایلێکی UTF-8 بە هەمان ١٢ سەردێڕ و ڕیزبەندیی [هەناردەی کاڵاکانی ZHIROX](CATALOG_EXPORT.md) هەڵبژێرە. هەناردەی کاتالۆگی بەتاڵ دەتوانێت وەک سەردێڕی فایلی نوێ بەکاربهێنرێت.
٣. «پشکنین و پێشبینین» بدە. هەموو ڕیزەکان پشکنین دەکرێن؛ زۆرترین ٥٠ ڕیز لە پێشبینیندا پیشان دەدرێن و ژمارەی تەواو دیارە. لەم قۆناغەدا هیچ کاڵایەک تۆمار نابێت.
٤. ناو، کۆد، دراو، نرخ، کارتۆن، بارکۆد و بڕی **سەرەتایی** لە پێشبینین و فایلی سەرچاوە پێداچوونەوە بکە. خانەی پشتڕاستکردنەوەی بڕی سەرەتایی هەڵبژێرە.
٥. «تۆمارکردنی هەموو کاڵاکان» بدە. ئەگەر ڕیزێک ڕەت بکرێتەوە، هیچ ڕیزێکی ئەو هاوردەیە تۆمار نابێت.

سنوور: ١٠٠٠٠ کاڵا و ٨ MiB بۆ هەر CSV. فایلە گەورەترەکان دەبێت بە فایلە بچووکترەکان دابەش بکرێن و هەر فایلێک سەردێڕی خۆی هەبێت؛ دابەشکردنی خۆکار هێشتا نییە. XLSX، فایلە `.kashir`، SQL Server `.bak` و schema ـی سیستەمی کۆن ڕاستەوخۆ پەسەند ناکرێن.

## یاسای داتا

- هەمان ١٢ خانەی CSV پێویستن؛ ناسنامەی کاڵای سەرچاوە و کاتی هەناردە نادەخرێنە داتابەیس. ناسنامە و کاتی تۆمارکردنی نوێ دروست دەبن.
- کۆدی ناوخۆ دەبێت تایبەت بێت. بارکۆد لە نێوان هەموو کاڵاکان و هەردوو یەکەی دانە/کارتۆن تایبەتە. دووبارەبوونەوە لە ناو فایل یان داتابەیسی ئێستا هەموو فایلەکە ڕەت دەکاتەوە؛ skip/merge یان overwrite ناکرێت.
- ناوی یەکسان بە کۆد و بارکۆدی جیا دەتوانێت دوو کاڵای جیا بێت؛ بە ناو یەک ناخڕێن.
- نرخەکانی IQD ژمارە تەواون؛ USD دۆلارە بە زۆرترین دوو ژمارەی دوای خاڵ. بڕی کۆگا دانەی بنەڕەتییە بە زۆرترین سێ ژمارەی دوای خاڵ. ژمارەی دانەی کارتۆن ژمارە تەواوە لە ١ تا ١٠٠٠٠٠. بڕ و نرخ نابێت نەرێنی بن؛ هیچ rounding یان ئاڵوگۆڕی دراو ناکرێت.
- بارکۆدەکان لیستی JSON ـی دەقن، وەک `["00001","00002"]`؛ JSON ـی ژمارە وەک `[123]` ڕەت دەکرێتەوە. زۆرترین ٥٠ بارکۆد بۆ هەر کاڵایەک؛ سفرەکانی سەرەتا دەپارێزرێن.
- بڕی CSV وەک **بڕی سەرەتایی کاڵای نوێ** تۆمار دەبێت، نە وەک زیادکردنەوەی بڕی کاڵای هەبوو. بۆیە پشتڕاستکردنەوەی دیاریکراو پێویستە.
- apostrophe ـی پاراستنی CSV کە لە هەناردەی دەقی شێوەفۆرمولە هەیە، خۆکار ناسڕدرێتەوە. ناو/کۆد لە پێشبینیندا پێداچوونەوە بکە؛ ئەمە round-trip ـی جێگرەوەی باکئەپ نییە.

## یەکپارچەیی و دووبارەکردنەوە

کاڵا، بارکۆدەکان، ledger ـی بڕی سەرەتایی، `product.created` ـی outbox، تۆماری هاوردە و audit ـی `products.imported` لە یەک transaction ـدا پاشەکەوت دەبن. لە هەر شکستێک هەموویان rollback دەکرێنەوە. هەموو پشکنینەکان لە تۆمارکردندا دووبارە ئەنجام دەدرێن؛ پشکنینی پێشوو کاڵای نوێی زیادکراو لە نێوان preview و commit پشتگوێ ناخات.

هاوردە ناسنامەی داواکاری و SHA-256 ـی دەقی CSV هەیە. ئەگەر وەڵام ون بوو، دوگمەکە هەمان داواکاری دووبارە دەنێرێت؛ وەڵامی پێشووی هەمان هەژمار/فایل دەگەڕێتەوە، تەنانەت دوای restart ـی سێرڤەر. بڕی کۆگا، outbox یان کاڵا دووبارە تۆمار نابێت. ناسنامەی هەمان داواکاری بۆ فایل یان هەژماری جیا ڕەت دەکرێتەوە. لە هەڵەی دڵنیای validation/conflict دا preview پاک دەکرێتەوە تا فایلەکە دووبارە بپشکنرێت.

**داخستنی پەنجەرە یان جێهێشتنی بەش داواکارییەکی پێشتر نێردراو هەڵناوەشێنێتەوە.** لە ئەنجامی نادیاردا سەرەتا هەمان داواکاری دووبارە پشتڕاست بکەرەوە؛ ئەگەر پەڕەکە داخرا، لیستی کاڵاکان و audit بپشکنە پێش هەوڵی نوێ. CSV و پێشبینین لە memory ـی ڕووکارە و بە داخستن/دەرچوون پاک دەکرێنەوە؛ localStorage بەکارناهێنرێت. تۆمارە پاشەکەوتکراوەکان ناگەڕێنەوە بە داخستنی ڕووکار.

پشکنین و هاوردە لە پرۆسەی ناوخۆی سێرڤەرن و ڕەنگە بۆ batch ـی گەورە داواکارییەکانی تر کەمێک چاوەڕێ بکەن. index ـی بارکۆد بەپێی کاڵا زیاد کراوە بۆ ئەوەی کۆکردنەوەی فرەبارکۆد بۆ هەر ڕیزێک پشکنینی تەواوی خشتە دووبارە نەکاتەوە. background job و undo ـی هاوردە هێشتا نییە.

## API و پاراستن

- `POST /api/products/import/preview` بە `{csv}`: ژمارەی ڕیز، fingerprint، یەکەم ٥٠ کاڵای پشکنراو و دۆخی تەواویی preview.
- `POST /api/products/import` بە `{csv,fingerprint,request_id,confirm_opening_stock:true}`: `batch_id`، `created` و `replayed`.

دانیشتن، CSRF، Host/Origin و دەسەڵات لە سێرڤەر دەپشکنرێن؛ دانیشتن دوای خوێندنەوەی upload دووبارە پشتڕاست دەکرێتەوە. JSON ـی upload تا ١٧ MiB ڕێگەپێدراوە بۆ escaping ـی فایلێکی CSV ـی ٨ MiB؛ API ـەکانی تر هەر سنووری پێشوویان هەیە. UTF-8 لە نێوان chunk ـەکانی HTTP دەپارێزرێت. کۆی CSV، ناو و بارکۆدەکان لە audit نییە؛ audit تەنها ژمارەی کاڵا و ناسنامەی batch هەڵدەگرێت.

کاڵاکان هەمان outbox ـی هاوکاتکردنی ئێستا بەکاردەهێنن؛ ئەمە ناردنی ڕاستەوخۆ یان cloud restore نییە. تۆماری idempotency ـی هاوردە ناوخۆییە و لە باکئەپی SQLite دەپارێزرێت.

## پشکنین و سنووری وەشان

١٠٤ تاقیکردنەوەی پڕۆژە لە Linux/Node 24 تێپەڕین: پشکنینی بێ نووسین، دەسەڵات/CSRF، JSON و UTF-8 ـی chunk کراو، quote/newline/JSON بارکۆد، وردی USD/stock، دووبارەبوونەوە و conflict ـی دوای preview، rollback لە شکستی audit/outbox، retry ـی هاوکات و دوای SQLite restart، retry دوای فرۆشتن و state controller ـی ڕووکار. پشکنینی بینراوی upload/confirm لە وێبگەڕ و Windows هێشتا نەکراون. هیچ کاتالۆگی ڕاستەقینەی مارکێت لەم قۆناغەدا هاوردە نەکراوە.

## مێژووی هاوردە — 0.15.0

لە بەشی کاڵاکان دوگمەی «مێژووی هاوردە» بکەرەوە. تەنها هاوردەی تەواوبوو و commit کراو لە SQLite دەردەکەوێت: کاتی تۆمارکردن بە کاتی عێراق، ناوی ئەنجامدەر، ژمارەی کاڵای ئەو batch ـە و دۆخی تۆمارکراو. preview، داواکاریی شکستخواردوو و rollback وەک هاوردەی سەرکەوتوو ناژمێردرێن. retry ـی هەمان داواکاری ڕیزێکی نوێ زیاد ناکات.

هەر پەڕەیەک ٢٥ هاوردە پیشان دەدات؛ «پێشوو/دواتر» بەپێی ناسنامەی جێگیری ڕیز پەڕە دەگۆڕن. هاوردەی نوێ لە کاتی بینینی پەڕەی کۆندا ڕیزەکان دووبارە ناکاتەوە. «نوێکردنەوە لە سەرەتا» کۆتا هاوردەکان دەخوێنێتەوە.

دەسەڵاتی `products.write` پێویستە. ئەگەر هەژمار `audit.read` ـی هەبێت، هەموو هاوردەکان دەبینێت؛ لە ڕۆڵەکانی ئێستادا خاوەن و بەڕێوەبەرن. کارمەندی کۆگا تەنها هاوردەکانی خۆی دەبینێت؛ کاشێر و هەژماری بێ دانیشتن ڕەت دەکرێنەوە. فلتەری actor لە داواکاری ناتوانێت ئەو سنوورە بگۆڕێت.

`GET /api/products/imports?limit=25&before=SEQUENCE` تا ٥٠ ڕیز وەردەگرێت و `scope`, `records`, `has_more`, `next_before` دەگەڕێنێتەوە. هەر ڕیز `sequence`, `batch_id`, `products`, `created_at`, `actor_name` هەیە. fingerprint، CSV، نرخ، بارکۆد و نهێنیی هەژمار لە لیستەکە نییە. بە جێهێشتنی بەش، داخستنی لیست یان کۆتایی دانیشتن وەڵامی کۆن پشتگوێ دەخرێت.

ژمارەی کاڵا لێرە ژمارەی کاڵای نوێی ئەو هاوردەیە لە کاتی تۆمارکردن، **نە بڕی کۆگای ئێستا**. ناوی ئەنجامدەر لە هەژماری ئێستایەتی. فایلە سەرچاوەکە و لیستی تاکەکاڵاکانی batch لەم لیستەدا نین؛ ئەمە گەڕاندنەوە یان undo نییە. دوای ئەنجامی نادیار، کات/ئەنجامدەر/ژمارە بپشکنە و لیستی کاڵاکانیش بەراورد بکە؛ لیستەکە هەر سەرکەوتنی تۆمارکردنی batch دەسەلمێنێت.

پشکنینە نوێکان سنووری هەژمار، نەدەرکەوتنی نهێنی، pagination ـی جێگیر لەگەڵ هاوردەی نوێ، فلتەری نادروست، HTTP و وەڵامی دوای داخستن/دەرچوون دەگرنەوە. هەموو ١٠٤ تاقیکردنەوە لە Linux/Node 24 تێپەڕین؛ پشکنینی بینراوی لیست لە وێبگەڕ و Windows هێشتا ماوە.
