# گەڕان و سکانی کاشێر — 0.18.0

کاشێر لە دەستپێکردن هەموو کاتالۆگ بار ناکات. تەنها سەبەتەی هەژمار و زانیاریی کاڵاکانی ناوی دەخوێندرێنەوە. ناو یان کۆد بنووسە؛ دوای ١٨٠ ms وەستان، گەڕان لە داتابەیسی ناوخۆ بە ٢٥ ئەنجام ئەنجام دەدرێت. «دواتر» پەڕەی دواتر دەهێنێت؛ دووبارە نووسین گەڕان لە سەرەتا دەست پێ دەکاتەوە. لیستی ئەنجامەکان تەنها پەڕەی ئێستا هەڵدەگرێت. گەڕانی بەتاڵ هەموو کاڵاکان بار ناکات.

## سکان و سەبەتە

بارکۆد سکان بکە و Enter بدە. بارکۆد بە تەواوی، لەگەڵ سفرەکانی سەرەتا، لە داتابەیس دەدۆزرێتەوە؛ یەکەی دانە یان کارتۆن لە هەمان بارکۆد وەردەگیرێت. بارکۆدی نەدۆزراوە یان نادروست هەڵەی ڕوون دەدات و هیچ کاڵایەکی جێگرەوە هەڵنابژێرێت. هەر سکانێک کردارێکی سەربەخۆیە؛ دوو سکانی هەمان بارکۆد دوو جار بڕ زیاد دەکات.

سکانەکان بە ڕیز چارەسەر دەکرێن، زۆرترین ٥٠ سکان لە چاوەڕوانی. ژمارەی چاوەڕوانەکان لە دۆخی سەبەتە دیارە. فرۆشتن تا تەواوبوونی ئەوانە و پاشەکەوتکردنی سەبەتە ڕادەگیرێت. هەڵەی lookup هیچ بڕێک زیاد ناکات؛ سکانەکە دووبارە بکەرەوە. شکستی پاشەکەوتکردن و ئەنجامی نادیاری checkout هەمان پاراستنی سەبەتە و idempotency ـی پێشوو بەکاردەهێنن.

کاتێک سەبەتەی پاشەکەوتکراو دەگەڕێتەوە، تەنها کاڵاکانی ناوی بە ناسنامە دەخوێندرێنەوە، تەنانەت ئەگەر لە پەڕەی گەڕاندا نەبن. ئەگەر lookup شکستی هێنا، خانەکانی دەستکاری/فرۆشتن قوفڵن و «خوێندنەوەی سەبەتەی پاشەکەوتکراو» دەردەکەوێت. تۆماری سەبەتەی SQLite ناسڕدرێتەوە.

گواستنەوە لە کاشێر یان کۆتایی دانیشتن گەڕان و سکانە lookup نەکراوەکان هەڵدەوەشێنێتەوە؛ وەڵامی دواخراو ناتوانێت کاڵا بخاتە سەبەتەی دانیشتنێکی تر. پێش گواستنەوە چاوەڕوانی سفرکردنەوەی سکانە چاوەڕوانەکان بکە. داخستنی پەڕە لە کاتی چاوەڕوانی ئاگادارکردنەوەی وێبگەڕ هەڵدەستێنێت؛ ئەو سکانانەی هێشتا lookup نەکراون پاشەکەوت نەکراون.

## API و پاراستن

- `GET /api/pos/barcode?code=`: بارکۆدی exact لە ١ تا ٦٤ پیت، هەمان یاسای بارکۆدی کاڵا. وەڵام `{product,unit}`؛ بارکۆد و کاڵا لە یەک read transaction دەخوێندرێنەوە.
- `POST /api/pos/products`: JSON ـی `{ids:[...]}`، تا ٢٠٠ ناسنامە. lookup ـی بێ نووسینە، بەڵام دانیشتن و CSRF پێویستە؛ سێرڤەر دوای خوێندنەوەی body دانیشتن دووبارە دەپشکنێت. ناسنامەی دووبارە یەک جار دەگەڕێتەوە، ناسنامەی ونبوو هەموو داواکارییەکە بە 404 ڕەت دەکاتەوە.
- هەردوو endpoint ـەکە `sales.create` و `products.read` دەوێت: خاوەن، بەڕێوەبەر و کاشێر. کارمەندی کۆگا ڕێگەی نییە. هیچ تێچووی کڕین یان زانیاریی هەژمار ناگەڕێتەوە.
- گەڕانی ناو/کۆد هەمان `/api/catalog` ـی پەڕەبەندکراو بەکاردەهێنێت. نرخی کۆتایی و بڕی کۆگا هەر لە checkout ـی سێرڤەر پشتڕاست دەکرێنەوە؛ ئەنجامی گەڕان نرخی قوفڵکراوی فرۆشتن نییە.

## پاراستنی بارکۆدی تەرازوو (0.26.0-dev.0)

لە چوارچێوەی QA، سکانکردنی بارکۆدی EAN-13 بە prefix ـی `27` و check digit ـی دروست بە 409 ڕەت دەکرێتەوە، چونکە وەرگێڕانی کێش/نرخ/ژمارەی دەستکردی تەرازوو هێشتا پشتڕاست نەکراوەتەوە. ئەگەر check digit نادروست بێت 400 دەگەڕێتەوە. لەم حاڵەتەدا هیچ کاڵا/نرخێک خۆکارانە ناخرێتە سەبەتەوە؛ بارکۆدە ئاساییەکانی دانە/کارتۆن وەک خۆیان کار دەکەن. [وردەکاری](HARDWARE_QA.md).

## پشکنین و سنوور

١٣١ تاقیکردنەوە و design checksum تێپەڕین. پشکنینە نوێکان lookup/دەسەڵات/CSRF، نەدەرکەوتنی تێچوو، سکانی دانە/کارتۆن، ڕیزبەندی و دووبارەی سکان، شکستی lookup، پشتگوێخستنی وەڵامی کۆن، queue limit، hydration و مانەوەی هێڵەکانی سەبەتە، شکستی بارکردن/دووبارە هەوڵدان، logout و قوفڵکردنی فرۆشتن لە کاتی چاوەڕوانی دەگرنەوە. هیچ داتای تاقیکردنەوە لە داتابەیسی کارکردن دانەنراوە.

پشکنینی بینراوی کاشێری چووەژوورەوە، Windows و سکانەری ڕاستەقینە هێشتا ماون. یاسای تەرازووی کێش و فرۆشتنی کەرتی هێشتا جێبەجێ نەکراون؛ بارکۆد وەک دەقی تەواوی تۆمارکراو دەخوێندرێتەوە. endpoint ـی کۆنی `/api/products` بۆ compatibility دەمێنێتەوە، بەڵام کاشێر و لیستی کاڵاکان بەکاری ناهێنن.
