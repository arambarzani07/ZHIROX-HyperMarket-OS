# کۆگا و مێژووی جووڵە — 0.6.0

لە کارتی کاڵا و کۆگا → کۆگا، بڕی بەردەستی کاڵاکانی SQLite پیشان دەدرێت. گەڕان بە ناو، کۆدی ناوخۆ یان بارکۆدی تەواوی دانە/کارتۆنە؛ سفرەکانی سەرەتای بارکۆد دەپارێزرێن. فلتەرەکان هەموو، بەردەست و بڕی سفرن. سنووری «کەمبووەوە» هێشتا ڕێک نەخراوە و بڕێکی خەیاڵی بۆی دانەنراوە.

بڕ بە دانەی بنەڕەتی لە هزارەکانی دانە دەپارێزرێت. «یەک کارتۆن» تەنها ژمارەی دانەکانی کارتۆن پیشان دەدات؛ بڕی کارتۆنی داخراو لە بڕی گشتی هەژمار ناکرێت. تێچوو و بەهای داراییی کۆگا لەم بەشەدا پیشان نادرێن.

«جووڵەی کۆگا» بڕی سەرەتایی و کەمبوونەوەی فرۆشتنە تۆمارکراوەکان دەکاتەوە. هەر ڕیز بڕی گۆڕان و بڕی دوای ئەو جووڵەیە پیشان دەدات. بەروار بە کاتی عێراقە. کۆی هەموو ledger ـی کاڵاکە لەگەڵ stock_milli بەراورد دەکرێت لە یەک read transaction؛ ئەگەر جیاوازی هەبێت ڕاپۆرت دەکرێت و هیچ چاککردنەوەیەکی خۆکار ناکرێت.

## دەسەڵات و پسوولە

دەسەڵاتی `products.read` بۆ لیست و مێژوو پێویستە. چوار ڕۆڵی ئێستا هەیانە؛ هیچ فیلدی تێچوو، password، session یان payload ـی فرۆشتن لە وەڵامەکان نییە.

خاوەن/بەڕێوەبەر لینکەکانی هەموو پسوولەکان دەبینن. کاشێر تەنها لینکەکانی پسوولەکانی خۆی دەبینێت؛ کارمەندی کۆگا لینکی پسوولە نابینێت. endpoint ـی وردەکاریی پسوولە سەربەخۆ دەسەڵات دەپشکنێت. جووڵەی کۆگا بەبێ دەسەڵاتی پسوولە هەر بە بڕ و بەروار پیشان دەدرێت، بەبێ reference_id ـی فرۆشتن.

## API و پەڕەبەندی

- `GET /api/inventory?q=&stock=&after=&limit=`: stock = بەتاڵ / `available` / `zero`. ڕیزبەندی SKU، ٢٥ کاڵا لە بنەڕەتدا و زۆرترین ٥٠. وەڵام: `products`, `has_more`, `next_after`.
- `GET /api/inventory/:id/ledger?before=&limit=`: نوێترین جووڵە سەرەتا. وەڵام: product، ledger_total_milli، reconciled، entries، has_more و next_before. بڕی دوای جووڵە لە هەموو ledger هەژمار دەکرێت پێش سنووردارکردنی پەڕە، بۆیە پەڕەکانی کۆن لە سفرەوە دەست پێ ناکەنەوە.

«نوێکردنەوە» بڕ و لیستی کاڵاکان دووبارە دەخوێنێتەوە. لیستەکە push ـی ڕاستەوخۆی گۆڕانکاری نییە؛ لە کاتی کارکردنی چەند پەڕەیەکدا نوێی بکەرەوە. هەر پەڕە ٢٥ ڕیز پیشان دەدات و دوگمەی زیاتر هەیە.

## ماوە و پشکنین

ژماردنی کۆگا، adjustment، کڕین، گەڕاندنەوە، شوێنی کۆگا، بەسەرچوون، ئاگادارکردنەوەی سنووری کەم و بەهای دارایی هێشتا جێبەجێ نەکراون. ئەم بەشە تەنها داتای پێشتر تۆمارکراو دەخوێنێتەوە؛ هیچ تۆماری نمایشی دانانێت و ledger ناگۆڕێت.

٣٧ تاقیکردنەوە تێپەڕین: بڕی کەرتی سەرەتایی، فرۆشتنی کارتۆن، مانەوەی بڕی مێژوویی لە پەڕەی کۆن دوای فرۆشتنی نوێ، جیاکردنەوەی لینکەکانی پسوولە بە ڕۆڵ، بارکۆدی سفرەدار، پەڕەبەندی، فلتەر، یەکگرتنەوەی ledger، ڕاپۆرتکردنی جیاوازیی ڕاستەقینە بەبێ چاککردنەوە، validation و دەسەڵاتی HTTP.

دیزاینی پەسەندکراو و checksum پارێزراون. پشکنینی بینراوی شاشەی چووەژوورەوە و Windows/ئامێری ڕاستەقینە لەم قۆناغەدا ئەنجام نەدراون.
