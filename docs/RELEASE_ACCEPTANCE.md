# ZHIROX — یاسای کۆتایی ئامادەبوون بۆ بەکارهێنانی ڕاستەقینە

**دۆخی ئێستا: 0.35.0-dev.0 / تەنها QA — نەک Production.**
ئەم بەڵگەنامەیە جێگای ژمارەکردنی قۆناغە بێ‌کۆتاییەکان دەگرێتەوە. بەکارهێنان لە مارکێت تەنها دوای پشتڕاستکردنەوەی هەموو مەرجەکانی خوارەوە پەسەند دەکرێت.

## A — بنەمای کۆد و پاراستن
- [x] GitHub branch ـی جیا `feat/offline-foundation`؛ PR ـەکە Draft و `main` بەبێ Merge.
- [x] دیزاینی ٦ کارت و RTL ـی پەسەندکراو بە checksum پارێزراوە.
- [x] Immutable Cash Ledger، Sales، Stock و Refund/Expense ـی جیا، transaction، RBAC و QA regression.
- [x] Windows QA ZIP ـی unsigned، Node 24 ـی تێخراو، SHA256 و داتای QA ـی جیا.
- [ ] هەموو یاسای بەکارهێنان و پەڕە سەرەکییەکان لە Windows ـی مارکێت لەلایەن خاوەن پشکنراون. **هێشتا نا**.

## B — داتابەیس و Cloud
- [x] PostgreSQL 17 ـی موقەتی بە داتای ساختە؛ RLS، tenant، replay و stock parity، هەموویان لە `ROLLBACK`.
- [x] QA ـی Edge Function لە کۆدی جیا، بە Project Ref allowlist و بێ ناردنی زانیاریی پارە.
- [x] پشکنەری 0.35 ـی دوو Snapshot و SHA-256 ـی داتابەیسی QA، بە Mock Staging، بەبێ پەیوەندیی ڕاستەقینە.
- [ ] **Supabase Staging ـی جیا** بە ڕێگەپێدانی خاوەن دیاری و دروستکراوە.
- [ ] Edge + SQL ـی Staging لە پڕۆژەیەکی جیا تاقیکراوەتەوە؛ هیچ بەشی Production نەگۆڕاوە.
- [ ] ناردن/وەرگرتنی ڕاستەقینەی stock-only Refund، API idempotency، offline/reconnect، checkpoint و دووبارەبوونەوە تاقیکراوەتەوە.
- [ ] هاوتایی تەواوی کاڵاکان لە SQLite و Staging بە داتای پەسەندکراو پشتڕاستکراوەتەوە.
- [ ] مێژووی Refund ـی کۆن و Outbox ـی ناتەواو بە پلانی پێداچوونەوەی دەستی چارەسەر کراوە؛ هیچ باکفیلی خۆکار نییە.

## C — کاشێر و هاردوێری ڕاستەقینە
- [ ] بارکۆد سکانەر لە Windows ـی مارکێت پشکنراوە.
- [ ] بارکۆدی تەرازووی `27 + 7-digit item code` بە **نمونەی ڕاستەقینە**ی نرخی/کێش پەسەند کراوە؛ تاکو ئەو کاتە سکانی scale ـی نەناسراو ڕەت دەکرێتەوە.
- [ ] پڕینتەری 58/80mm لەسەر کاغەزی ڕاستەقینە، کوردی RTL، پسوولەی دووبارە و قطعبوونی کارەبا تاقیکراوەتەوە.
- [ ] سندوقی پارە / cash drawer، فرۆشتن و Refund و Shift ـی نوێ بە داتای QA پشکنراوە.
- [ ] کڕین، فرۆشتن، کۆگا، دابینکەر و پسوولە لەگەڵ کاری ڕۆژانەی سوپەرمارکێت یەک بە یەک پەسەندکراون.

## D — ئاسایش و Recovery
- [ ] شاردنەوەی هەموو token/key و پشکنینی Permission و Audit لە ژینگەی بڵاوکردنەوە تەواوە.
- [ ] باکئەپ، Recover بۆ فولدەری جیا، Power outage، دوبارەکردنەوەی داواکاری، و downgrade fail-closed لە Windows ـی مارکێت تاقیکراونەتەوە.
- [ ] بەڵگەی ڕەزامەندی خاوەن بۆ گۆڕینی بۆ Production بەدەستهاتووە.
- [ ] Windows build ـی فەرمی بە signer/installer و ناوی وەشان و کۆنترۆڵی rollback ئامادەیە.

## قوفڵەکانی ئێستا
- `ZHIROX_CASH_ACCOUNTING`، `ZHIROX_PURCHASE_POSTING` و `ZHIROX_ADJUSTMENT_POSTING` بە بنەڕەت OFF ـن؛ لانچەری QA ناچالاکیان دەکات.
- هیچ بڕی پارە، Cash Ledger یان Expense ـێک لە Cloud ـی stock-only بڵاو ناکرێتەوە.
- ناردنی Cloud ـی Refund بە ڕاستەقینە قوفڵە، هەرچەندە QA ـی ساختە PASS بێت.
- سیستەمی کۆن (`Admin.exe`, `Cashier.exe`, SQL Server و ئامێرەکان) **١٠٠٪ تەنها خوێندنەوە**یە تا ڕێگەپێدانی جیا.
- **بەهۆی PASS بوونی CI ـەوە سیستەم بە خۆکار نانرێتە Production**. بەڵگەی پشکنینی هاردوێری ڕاستەقینە و پەسەندکردنی خاوەن پێویستە.

پاش تێپەڕاندنی ئەم پشکنینانە، release candidate ـی یەکگرتوو دروست دەکرێت؛ پێش ئەوە تەنها QA distribution ئامادەیە.
