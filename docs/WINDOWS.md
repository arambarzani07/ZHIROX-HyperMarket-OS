# پاکێجی کارپێکردنی Windows — 0.9.0

ئەم پاکێجە سەرچاوەی سیستەمە لە ZIP ـێکدا. Node.js 24 یان نوێتر دەبێت لە کۆمپیوتەرەکە دامەزرابێت. EXE، Node ـی تێخراو، دامەزرێنەری یەکجارەکی و نوێکردنەوەی خۆکار هێشتا دروست نەکراون.

## دەستپێکردن

١. ZIP ـەکە دەربهێنە؛ فایلەکان لە ناو ZIP ڕاستەوخۆ مەکەرەوە.
٢. `scripts/check-windows.cmd` بکەرەوە. Node 24+، SQLite و مۆڵەتی نووسین لە فۆڵدەری داتا دەپشکنێت؛ داتابەیسی ڕاستەقینە ناکاتەوە و داتای تاقیکردنەوەی تێدا دانانێت.
٣. دوای سەرکەوتن `scripts/start-windows.cmd` بکەرەوە و `http://127.0.0.1:3187` لە هەمان کۆمپیوتەر بکەرەوە. پەنجەرەی سێرڤەر بە کراوەیی بهێڵەوە.
٤. لە یەکەم کردنەوەدا هەژماری خاوەن دروست بکە. هیچ پاسۆرد، کاڵا یان فرۆشتنی ئامادە لە پاکێجەکە نییە.
٥. بۆ کلاود [SYNC.md](SYNC.md) جێبەجێ بکە؛ پاکێجەکە هیچ ناسنامەی نهێنیی ئامێرێکی تر هەڵناگرێت.

لە دامەزراندنی نوێدا داتا لە `%LOCALAPPDATA%\ZHIROX-HyperMarket-OS\data` دەپارێزرێت. پشکنین شوێنی بەکارهاتوو پیشان دەدات. بە هەمان هەژماری Windows کارپێ بکە؛ هەژمارێکی تری Windows شوێنی LOCALAPPDATA ـی جیاوازی هەیە.

بۆ وەشانی کۆن کە داتاکەی لە ناو فۆڵدەری ئەپە، [ڕێنمایی پاراستنی ڕێڕەوی داتا](RUN.md) پەیڕەو بکە. هیچ فۆڵدەری داتایەک مەسڕەوە و داتابەیسەکان بە یەکەوە مەنووسەرەوە.

## دروستکردنی پاکێج لە سەرچاوە

لە checkout ـێکی پاک و commit کراودا:

```sh
npm run check
npm test
npm run package:windows
```

Git تەنها بۆ دروستکردنی ZIP پێویستە؛ بۆ کارپێکردن لە Windows پێویست نییە. build تەنها سەرچاوەی commit کراو کۆ دەکاتەوە؛ داتابەیس، باکئەپ، فایلی runtime و نهێنیی ئامێر تێدا نین. لە `dist/` فایلەکانی ZIP و SHA-256 دروست دەبن. بۆ پشکنینی ZIP لە PowerShell:

```powershell
Get-FileHash .\ZHIROX-Windows-Portable-0.9.0.zip -Algorithm SHA256
```

بەهاکە لەگەڵ فایلەکەی `.sha256` بەراورد بکە.

## دۆخی پشکنین

- ڕێڕەوی Windows بە Win32 path semantics تاقی کراوەتەوە: شوێنی جێگیر، ڕێڕەوی تایبەت، داتای کۆن و دۆخی هەبوونی دوو داتابەیس.
- پشکنینی Node/SQLite، سەرکەوتن و شکستی نووسین، و دەستنەدانی داتابەیس/ناسنامە لە Linux تاقی کراونەوە.
- ڕێڕەوی HTTP و ٥٣ تاقیکردنەوەی پڕۆژە تێپەڕین؛ دیزاینی قوفڵکراو نەگۆڕاوە.
- Windows، فایلەکانی CMD، پڕینتەر، تەرازوو و کشووی پارە لە ئامێری ڕاستەقینە هێشتا تاقی نەکراونەوە.
