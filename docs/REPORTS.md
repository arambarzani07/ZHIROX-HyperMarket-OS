# ڕاپۆرتی فرۆشتنی نەقد — 0.13.0

لە کارتی دارایی و ڕاپۆرت → ڕاپۆرتەکان، خاوەن و بەڕێوەبەر دەتوانن کۆی فرۆشتنی تۆمارکراوی SQLite ببینن. ئەمە دەسەڵاتی نوێی `reports.read` ـە؛ کاشێر و کارمەندی کۆگا هەیان نییە. هەموو پشکنینەکان لە سێرڤەر جێبەجێ دەکرێن.

## ژمارەکان

بۆ هەر دراوێک بە جیا، IQD و USD:

- کۆی فرۆشتن: کۆی نرخی پسوولە تۆمارکراوەکان.
- ژمارەی پسوولەکان.
- پارەی وەرگیراو پێش گەڕاوە: ئەو پارەیەی کڕیار پێی داوە، لەگەڵ ئەو بەشەی دواتر گەڕاوەتەوە.
- پارەی گەڕاوە: received − total.

خشتەی ڕۆژانە هەمان ژمارەکان بە ڕۆژ و دراو جیا دەکاتەوە. هیچ exchange rate یان کۆی تێکەڵی دینار/دۆلار هەژمار ناکرێت. لە داتابەیسی بەتاڵدا کۆ و ژمارەی پسوولە سفرە و خشتەی ڕۆژانە بەتاڵە؛ هیچ چارت یان داتای نمایشی نییە.

## بەروار

بنەڕەت ڕۆژی ئەمڕۆ بە کاتی عێراقە. بەرواری سەرەتا و کۆتایی هەردووکیان بە تەواوی دەگرێتەوە بە UTC+03:00. مەودا زۆرترین ٣٦٦ ڕۆژە و بەروارەکان لە 2000 تا 9998 پەسەند دەکرێن. «نوێکردنەوە» هەمان هەڵبژاردنی پێشوو دووبارە دەخوێنێتەوە؛ کاتی خوێندنەوە پیشان دەدرێت. گۆڕانکارییەکان push ـی ڕاستەوخۆ نین.

## API و وردی

`GET /api/reports/sales?from=YYYY-MM-DD&to=YYYY-MM-DD`

ئەگەر هەردوو بەروار بەتاڵ بن، ئەمڕۆ هەڵدەبژێردرێت؛ ئەگەر تەنها یەکێکیان بدرێت، هەمان ڕۆژە. وەڵام: `from`, `to`, `time_zone`, `as_of`, `totals`, `days`.

هەر کۆێک `currency`, `receipts`, `total_minor`, `received_minor`, `change_minor` هەڵدەگرێت. بڕە پارەییەکان بە **دەقی ژمارەی تەواو** دەنێردرێن: IQD بە دینار و USD بە سنت. کۆکردنەوە لەسەر integer/BigInt ـە؛ لە JavaScript Number یان SQLite SUM بەکارناهێنرێت بۆ کۆکردنەوەی پارە، تا لە ژمارە گەورەکان وردی نەفەوتێت. ڕووکار ژمارەکان بە BigInt دەنوسێتەوە بەبێ گۆڕین بۆ floating-point.

ڕاپۆرت هیچ نووسینێک لە فرۆشتن، کۆگا، سەبەتە، ledger یان outbox ناکات. هیچ ناوی کڕیار، پاسۆرد، session، تێچووی کاڵا یان request payload لە API ـەکە نییە.

## سنوور و پشکنین

ئەم ڕاپۆرتە تەنها پسوولەکانی فرۆشتنی نەقد هەژمار دەکات. خەرجی، قەرز، قازانج، cash session، بڕی ڕاستەقینەی کشوو، گەڕاندنەوە و جیاوازی ژماردنی پارە هێشتا جێبەجێ نەکراون. هەناردەی CSV و پەڕەی چاپ لە 0.7.1 زیاد کران.

٨٤ تاقیکردنەوەی پڕۆژە سەرکەوتوون؛ لەوانە ڕاپۆرتی بەتاڵ، جیاکردنەوەی دراو، received/change، کۆی گەورەتر لە Number.MAX_SAFE_INTEGER، وردی سنتی USD لە ڕووکار، سنووری نیوەشەو لە عێراق، ساڵی کەبیسە، بەرواری نادروست، زۆرترین مەودا و دەسەڵاتی هەموو ڕۆڵەکان لە HTTP.

دیزاینی قوفڵکراو و checksum پارێزراون. پشکنینی بینراوی ڕاپۆرت دوای چوونەژوورەوە و تاقیکردنەوەی Windows/ئامێری ڕاستەقینە لەم قۆناغەدا ئەنجام نەدراون.

## هەناردە و چاپ — 0.7.1

دوای باربوونی ڕاپۆرت، «هەناردەی CSV» فایلێکی UTF-8 بە BOM، سەردێڕی کوردی و CRLF دادەگرێت. دوو ڕیزی کۆی مەودا بە جیا بۆ IQD/USD و ڕیزە ڕۆژانە هەیە؛ خانەی «جۆری ڕیز» جیاوازییان دیاری دەکات. کۆی مەودا و ڕیزە ڕۆژانە دوو جار لەگەڵ یەک کۆ مەکەرەوە.

CSV بڕەکان بە دینار و دۆلار دەنووسێتەوە: USD بە دوو ژمارەی دوای خاڵ و IQD بە ژمارەی تەواو، بەبێ کۆمای هەزارەکان. کاتی خوێندنەوە و بەرواری مەودا لە هەر ڕیزدا هەن. فایلەکە وردی دەق دەپارێزێت؛ Excel لە کردنەوەی خۆکاردا ڕەنگە ژمارەی زیاتر لە ١٥ رقم خڕ بکاتەوە، بۆ ئەو بڕانە خانەکانی پارە بە Text هاوردە بکە.

«چاپی ڕاپۆرت» پەڕەی چاپ دەکاتەوە لەگەڵ کۆی هەر دراوێک، وەرگیراو/گەڕاوە و خشتەی ڕۆژانەی فرۆشتن. دوگمەی «چاپ» دیالۆگی چاپی وێبگەڕ دەکاتەوە. PDF تەنها ئەگەر لە دیالۆگی وێبگەڕ هەڵبژێردرێت؛ فایلێکی PDF خۆکار دروست ناکرێت.

هەردوو کردار هەمان snapshot ـی ڕاپۆرتی پیشاندراو بەکاردەهێنن؛ query یان نووسینی نوێ بۆ داتابەیس ناکەن. گۆڕینی بەروار لە فۆڕم تا «پیشاندانی ڕاپۆرت» نەدرێت، هەناردەکە هەر بۆ ڕاپۆرتی پێشتر پیشاندراوە. لە کاتی بارکردن یان هەڵەدا دوگمەکان ناچالاکن؛ بە جێهێشتنی بەش یان کۆتایی دانیشتن snapshot و پەڕەی چاپ پاک دەکرێنەوە. فایلێکی پێشتر داگیراو لە ئامێری بەکارهێنەر دەمێنێتەوە.

تاقیکردنەوەکانی CSV، کۆی گەورە، سنت، metadata، formula ـی نادروست، ڕاپۆرتی بەتاڵ و HTML ـی چاپ تێپەڕین. دیالۆگی داگرتن/چاپ و ڕێکخستنی پەڕە لە وێبگەڕ و پڕینتەری ڕاستەقینە لەم قۆناغەدا تاقی نەکراونەوە.

## فرۆشتن بەپێی کاڵا — 0.13.0

لە فۆڕمی ڕاپۆرت، جۆرەکە بکە «فرۆشتن بەپێی کاڵا»، بەروارەکان هەڵبژێرە و «پیشاندانی ڕاپۆرت» بدە. هەمان دەسەڵاتی `reports.read` بۆ خاوەن/بەڕێوەبەر پێویستە. کاشێر و کارمەندی کۆگا دەستگەیشتنیان نییە.

هەر گرووپێک بەپێی **ناسنامەی کاڵا + دراو + یەکەی فرۆشتن** دروست دەبێت. دوو کاڵای هەمان ناو یەک ناخرێن. دانە و کارتۆن ڕیزی جیایان هەیە؛ IQD/USD تێکەڵ ناکرێن. تەنها کاڵای فرۆشراو لە مەوداکەدا دەردەکەوێت، نە هەموو کاتالۆگ.

- ناو: کۆتا ناوی تۆمارکراوی کاڵا لە هێڵی فرۆشتن لە ناو مەوداکە؛ گۆڕینی دواتری کاتالۆگ ڕاپۆرتەکە ناگۆڕێت.
- بڕی فرۆشراو: کۆی `quantity` بە یەکەی ئەو ڕیزە، دانە یان کارتۆن.
- بڕ بە دانەی بنەڕەتی: کۆی `base_milli` ـی مێژوویی بە سێ ژمارەی دوای خاڵ. دانەی ئێستای کارتۆن دووبارە لەسەر فرۆشتنی کۆن ناهەژماردرێتەوە.
- کۆی فرۆشتن: کۆی `line_total` ـی تۆمارکراو؛ نرخی ئێستای کاڵا بەکارناهێنرێت.
- پسوولە: ژمارەی پسوولەی جیاواز کە ئەو کاڵا/یەکەیەیان تێدایە. چەند هێڵی هەمان کاڵا لە یەک پسوولەدا تەنها یەکجار بۆ ئەو گرووپە هەژمار دەکرێت.

کۆی هەر دراوێک ژمارەی پسوولەی جیاوازی خۆی هەیە. **ژمارەی پسوولەی گرووپەکان کۆ مەکەرەوە**؛ یەک پسوولە دەتوانێت چەند کاڵا یان یەکەی تێدا بێت. ڕیزەکان بەپێی دراو، پاشان کۆی فرۆشتنی زۆرتر ڕیز دەکرێن؛ نرخەکانی دوو دراو لەگەڵ یەک بەراورد ناکرێن. ئەمە فرۆشتنی تۆمارکراوە، نە قازانج یان فرۆشتنی دوای گەڕاندنەوە.

### API، سنوور و snapshot

`GET /api/reports/products?from=YYYY-MM-DD&to=YYYY-MM-DD`

بەروار و سنووری ٣٦٦ ڕۆژ هەمان یاسای ڕاپۆرتی ڕۆژانەیە. وەڵام `kind: product-sales`، `from/to/time_zone/as_of`، ژمارەی هێڵ (`lines`)، `totals` و `groups` هەڵدەگرێت. بڕی یەکە، دانەی بنەڕەتی و پارە لە API بە دەقی integer دێن؛ هەژمارکردن بە BigInt ـە و لە SQLite SUM یان floating-point بۆ کۆکردنەوە بەکارناهێنرێت. پارەی وەرگیراو/گەڕاوە بە کاڵا دابەش ناکرێت و تێچوو/زانیاریی چوونەژوورەوە هەناردە ناکرێت.

یەک query کاڵاکانی پسوولە بە ڕیزبەندی مێژوویی لە یەک snapshot دەخوێنێتەوە. لە ٢٥٠٠٠٠ هێڵ یان ١٠٠٠٠ گرووپ زیاتر، 413 دەگەڕێتەوە و داوای کەمکردنەوەی مەودا دەکرێت؛ ڕاپۆرت بە نهێنی نابڕدرێت و ئەنجامی بەشەکی نانێردرێت. ئەمە هەژمارکردنی ناوخۆیی لە پرۆسەی سێرڤەرە؛ background reporting هێشتا نییە.

ڕووکار هەر پەڕەیەکی ١٠٠ گرووپ پیشان دەدات. گۆڕینی پەڕە query ـی نوێ ناکات و هەمان snapshot دەپارێزێت. CSV و چاپ **هەموو گرووپەکانی** ڕاپۆرتەکە دەگرنەوە، نە تەنها پەڕەی ئێستا. CSV دوو ڕیزی کۆی مەودا و ڕیزەکانی کاڵا هەیە؛ کۆی مەودا و ڕیزەکان دووبارە لەگەڵ یەک کۆ مەکەرەوە. ناوی کاڵای شێوەفۆرمولە بە apostrophe دەپارێزرێت و HTML ـی چاپ escape دەکرێت. بۆ ژمارە گەورەکان، خانەکانی CSV لە Excel بە Text هاوردە بکە.

گۆڕینی جۆر/بەروار لە فۆڕم تا دوگمەی پیشاندان نەدرێت، ڕاپۆرتی پیشاندراو و هەناردە ناگۆڕێت. لە load/error، CSV و چاپ ناچالاکن؛ جێهێشتنی بەش یان دەرچوون snapshot ـی کۆن پاک دەکاتەوە.

### پشکنینی نوێ

داتای بەتاڵ، دەسەڵات/HTTP، سنووری بەرواری عێراق، فرۆشتنی دانە/کارتۆن و هێڵی دووبارە، دوو کاڵای هەمان ناو، دراوی جیاواز، ناو و نرخی مێژوویی، کۆی گەورەتر لە JS safe integer و SQLite SUM، ڕەتکردنەوەی ١٠٠٠١ گرووپ، CSV/چاپ، escape ـی ناو و VM ـی ڕووکار بۆ پەڕەبەندی/هەناردەی تەواو و وەڵامی کۆن تاقی کراونەوە. هەموو ٨٤ تاقیکردنەوە لە Linux/Node 24 تێپەڕین. تاقیکردنەوەی بینراوی ڕاپۆرتی نوێ، چاپ و Windows لە ئامێری ڕاستەقینە هێشتا ماون.
