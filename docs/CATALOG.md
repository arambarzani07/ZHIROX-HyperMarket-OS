# لیستی کاڵاکان — 0.17.0

لە کاڵا و بارکۆد، هەر پەڕە ٢٥ کاڵا لە داتابەیس بار دەکات. دوگمەکانی پێشوو/دواتر بۆ گواستنەوەن. ژمارەی ڕیزەکانی پەڕە و کۆی ئەنجامەکان بە جیا پیشان دەدرێن. ناو، بەشێک لە کۆدی ناوخۆ یان بارکۆدی تەواو بنووسە و «گەڕان» بکە؛ گەڕان لە هەموو کاتالۆگەکەیە، نەک تەنها لە پەڕەی پیشاندراو.

«نوێکردنەوە» هەمان گەڕان لە پەڕەی یەکەم دەست پێ دەکاتەوە. کاڵای نوێ، هاوردەی CSV، مێژووی هاوردە و هەناردەی هەموو کاڵاکان بە دەسەڵاتی پێشوو دەمێننەوە. هەناردەی کاتالۆگ فلتەری ئەم لیستە وەرناگرێت؛ ناوی دوگمەکە «هەموو کاڵاکان · CSV» ـە.

## API

`GET /api/catalog?q=&after=&limit=` دەسەڵاتی `products.read` پێویستە. limit لە ١ تا ٥٠، بنەڕەت ٢٥؛ گەڕان تا ٢٠٠ پیت و after کۆدی SKU ـی پەڕەی پێشوو تا ٨٠ پیتە. پارامەتری نەناسراو ڕەت دەکرێتەوە. وەڵام: `products`, `total`, `has_more`, `next_after`. `total` کۆی ئەنجامەکانی گەڕانە، بەبێ کاریگەریی after. بارکۆدەکانی هەر کاڵا تەواو دەگەڕێنەوە؛ کاڵا لە نێوان دوو پەڕە دابەش نابێت. تێچووی کڕین بۆ هیچ ڕۆڵێک لەم endpoint ـەدا نییە.

کۆی ئەنجامەکان و ڕیزەکانی هەر وەڵام لە یەک read transaction ـدا دەخوێندرێنەوە. ڕیزبەندی بە SKU و cursor ـە؛ زیادکردنی کاڵای پێش cursor ڕیزەکان دووبارە ناکاتەوە. هەر داواکاری snapshot ـی نوێیە؛ لە کاتی زیادکردنی کاڵا/فرۆشتن، ژمارە و بڕەکان دەکرێت لە نێوان پەڕەکان بگۆڕێن. بۆ دەستپێکردنەوە نوێکردنەوە بکە.

## پشکنین و سنوور

دەسەڵات و HTTP، فلتەر، ژمارەی گشتی، فرەبارکۆد، ڕێگری لە دەرکەوتنی تێچوو، وردی نرخی گەورە، HTML escaping، پشتگوێخستنی وەڵامی کۆن، retry و fixture ـی ٤٨٠٠٠ کاڵا لە SQLite ـی کاتی تاقی کرانەوە. هەموو ١١٩ تاقیکردنەوە و پشکنینی دیزاینی قوفڵکراو تێپەڕین. هیچ داتای تاقیکردنەوە لە داتابەیسی کارکردن دانەنراوە.

پشکنینی بینراوی شاشەی چووەژوورەوە و Windows هێشتا ماوە. گەڕانی کاشێر و endpoint ـی کۆنی `/api/products` هێشتا هەموو کاڵاکان بار دەکەن؛ ئەم وەشانە بەشی کاشێر پەڕەبەندی ناکات. لیستی کاڵاکان هیچ نرخ، کۆگا، ledger یان outbox ناگۆڕێت.
