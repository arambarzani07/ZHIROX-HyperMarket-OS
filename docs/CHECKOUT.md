# سەبەتەی پارێزراو — 0.4.0

سەبەتە، یەکەی دانە/کارتۆن، ژمارە و دەقی پارەی وەرگیراو لە SQLite بۆ هەر هەژمارێک بە جیا پاشەکەوت دەبن. تۆمارکردنی سەبەتە کۆگا یان پارە ناگۆڕێت؛ فرۆشتن هێشتا تەنها بە دوگمەی تۆمارکردن ئەنجام دەدرێت. سەبەتەکان بۆ کلاود نانێردرێن؛ لە باکئەپی SQLite هەن.

## ڕەفتاری کاشێر

- هەر گۆڕانکارییەک بە ڕیز بۆ سێرڤەری ناوخۆ دەنێردرێت. پەیامی «پاشەکەوتکردن…» دەگۆڕێت بۆ «پاشەکەوت کراوە» دوای وەڵامی سێرڤەر؛ تا ئەو کاتە پارێزراو نییە. تا کۆتایی پاشەکەوتکردن تۆمارکردنی فرۆشتن ناچالاکە.
- نوێکردنەوەی پەڕە، داخستنی وێبگەڕ یان دەرچوون و چوونەژوورەوە بە هەمان هەژمار، سەبەتەی پاشەکەوتکراو دەگەڕێنێتەوە. هەژماری تر سەبەتەی خۆی دەبینێت.
- سەبەتە revision ـی هەیە. پەڕەیەکی کۆن ناتوانێت سەبەتەی نوێتر بنووسێتەوە؛ پەیام و دوگمەی خوێندنەوەی وەشانی پاشەکەوتکراو پیشان دەدرێن. ئەو دوگمەیە گۆڕانکاریی پاشەکەوتنەکراوی ئەم پەڕەیە جێدەهێڵێت و دۆخی سێرڤەر دەخوێنێتەوە.
- فرۆشتن، کەمکردنەوەی کۆگا، ledger، outbox و بەتاڵکردنی سەبەتە لە یەک transaction ـدان. ئەگەر هەر بەشێک سەرکەوتوو نەبێت هەمووی rollback دەکرێت.
- ونبوونی وەڵام یان هەڵەی 5xx، هەمان request_id بۆ retry دەپارێزێت و دەستکاریی سەبەتە قوفڵ دەکات. دووبارە تۆمارکردن هەمان پسوولە دەگەڕێنێتەوە؛ فرۆشتنی دووەم دروست ناکات.
- ئەگەر پەڕەکە دوای تۆماربوونی فرۆشتن پچڕا، لە گەڕانەوەدا سەبەتە بەتاڵە و دوگمەی کۆتا پسوولەی هەژمار هەیە. retry ـی کۆن سەبەتەی نوێی دواتر ناسڕێتەوە.
- نرخ، دراو، کۆگا و بڕی پارە لە سێرڤەر پشکنین دەکرێن؛ نرخی نێردراوی وێبگەڕ باوەڕپێکراو نییە. فرۆشتنێکی ڕەتکراوە سەبەتەکە ناپاکاتەوە.

## سنوور و پشکنین

گۆڕانکارییەک کە وەڵامی پاشەکەوتکردنی نەهاتووە لە دۆخی پچڕاندا ڕەنگە نەگەڕێتەوە. پەڕە ئاگاداریی داخستن دەدات لە کاتی ناردن/هەڵەدا؛ ئەمە جێگرەوەی پشتڕاستکردنەوەی سێرڤەر نییە. هیچ browser localStorage ـێک بۆ داتای سەبەتە بەکارنەهاتووە.

`GET /api/cart`، `PUT /api/cart` و `POST /api/cart/checkout` پێویستیان بە دانیشتنی چالاک و دەسەڵاتی `sales.create` هەیە؛ نووسینەکان CSRF پێویستە. actor لە دانیشتن وەردەگیرێت، نە لە body ـی داواکاری. endpoint ـی کۆنی `/api/sales` بۆ سازگاری هەیە؛ ڕووکاری کاشێر تەنها ڕێڕەوی سەبەتەی نوێ بەکاردەهێنێت.

پشکنینەکان: restart ـی SQLite، IQD/USD، جیاوازی هەژمار، stale revision، تێکچوونی دوو پەڕە، lost acknowledgement، retry، پاراستنی سەبەتەی نوێ لە retry ـی کۆن، rollback ـی کۆگا و outbox، ڕەتکردنەوەی CSRF/دەسەڵات، serial saves و پشتگوێخستنی وەڵامی کۆنی دانیشتن. ٣١ تاقیکردنەوەی پڕۆژە سەرکەوتوون.

پشکنینی بینراوی ڕووکاری کاشێر دوای چوونەژوورەوە و تاقیکردنەوەی Windows/ئامێری ڕاستەقینە لەم قۆناغەدا ئەنجام نەدراون. دیزاینی پەسەندکراوی ٦ کارت و checksum نەگۆڕاون.
