# هەناردەی کاڵاکان — 0.12.0

لە بەشی کاڵاکان، دوگمەی «هەموو کاڵاکان · CSV» لیستی ڕاستەقینەی کاڵاکانی داتابەیسی ناوخۆ ئامادە دەکات. ئەم هەناردەیە هەموو کاڵاکان دەگرێتەوە؛ گەڕانی شاشە فلتەری فایلەکە نییە. هەر کاڵایەک یەک ڕیزی هەیە، تەنانەت ئەگەر چەند بارکۆدێکی هەبێت. داتابەیسی بەتاڵ تەنها سەردێڕ دەردەکات و هیچ ڕیزی نموونە یان کۆی ساختە زیاد ناکات.

## دەسەڵات و ناوەڕۆک

`products.export` بۆ خاوەن، بەڕێوەبەر و کارمەندی کۆگا هەیە. کاشێر ڕەت دەکرێتەوە؛ فایلەکە نرخی کڕینی تێدایە و دەبێت بە داتای تایبەتی مارکێت هەژمار بکرێت.

خانەکان: ناسنامە، ناوی کاڵا، کۆدی ناوخۆ، دراو، نرخی دانە، نرخی کڕینی دانە، ژمارەی دانەی کارتۆن، نرخی کۆی کارتۆن، بڕی ئێستای بەردەست بە دانەی بنەڕەتی، بارکۆدەکانی دانە، بارکۆدەکانی کارتۆن و کاتی هەناردە UTC.

نرخەکانی IQD دینارن؛ USD بە دۆلار و دوو ژمارەی دوای خاڵ دەنووسرێت. بڕی کۆگا سێ ژمارەی دوای خاڵ هەیە. هەموو گۆڕانکارییە ژمارەییەکان بە BigInt/دەقن و بڕە گەورەکان بە float ناگۆڕدرێن. هیچ ئاڵوگۆڕی دراو یان هەژمارکردنی قازانج ناکرێت.

بارکۆدەکان لە دوو خانەی JSON دێن، وەک `["00001","00002"]`، بە ڕیزبەندی جێگیر. سفرەکانی سەرەتا و جیاوازیی دانە/کارتۆن دەپارێزرێن. کاڵای بێ بارکۆد `[]` هەیە. کاڵاکانی هەمان ناو یەک ناخڕێن و هیچ تۆمارێک نالادەبرێت.

## فایل و Excel

فایلەکە UTF-8 بە BOM، CRLF و خانەی quote کراوە؛ ناوی کوردی، کۆما، quote و newline لە ناو ناوەکان بە شێوەی CSV دەپارێزرێن. دەقێک کە وەک فۆرمولەی spreadsheet دەست پێ بکات، apostrophe ـێکی پاراستنی لە پێشەوە دادەنرێت؛ ناوەڕۆکی داتابەیس ناگۆڕێت.

لە Excel بە ڕێگای Import/Text-CSV فایلەکە بکەرەوە و کۆدی ناوخۆ و خانەکانی JSON بە Text دیاری بکە. کردنەوەی ڕاستەوخۆ بە double-click ڕەنگە Excel کۆدی ژمارەیی یان بڕی زۆر گەورە خۆکار بگۆڕێت؛ CSV خۆی زانیاریی جۆری ستوون هەڵناگرێت. ئەم فایلە import ـی خۆکار یان باکئەپی SQLite نییە.

## API و سنوور

`GET /api/products/export.csv` دانیشتنی چالاک و دەسەڵاتی هەناردە پێویستە. هیچ query/filter وەرناگرێت. وەڵام `text/csv; charset=utf-8`، attachment و `Cache-Control: no-store` ـە؛ ژمارەی کاڵا و کاتی snapshot لە `X-Zhirox-Product-Count` و `X-Zhirox-Exported-At` دێن. یەک join و یەک read transaction کاڵا و بارکۆدەکان لە هەمان snapshot دەخوێننەوە، بەبێ query ـی جیا بۆ هەر کاڵایەک.

سنووری فایل ٣٢ MiB ـە؛ لە تێپەڕاندنی سنووردا 413 دەگەڕێتەوە، هیچ فایلێکی بڕاو/ناتەواو ناگەڕێندرێتەوە و هیچ کاڵایەک بە نهێنی ناخرێتە دەرەوە. ئامادەکردنی فایل لە پرۆسەی سێرڤەری ناوخۆیە و بۆ کاتالۆگی گەورە ڕەنگە کاتێکی کورت داواکارییەکانی تر چاوەڕێ بکەن؛ background export هێشتا نییە.

ڕووکار داواکاریی دووبارە لە کاتی ئامادەکردندا ڕادەگرێت. وەڵامی دوای گواستنەوەی بەش، دەرچوون یان گۆڕینی دانیشتن نابێتە فایلێکی نوێی داگرتن. فایلێکی پێشتر داگیراو لە ئامێری بەکارهێنەر دەمێنێتەوە.

## پشکنین

٧٤ تاقیکردنەوەی پڕۆژە لە Linux/Node 24 تێپەڕین. پشکنینە نوێکان داتای بەتاڵ، دەسەڵات/Origin/HTTP، ژمارەی ڕیز، فرەبارکۆد، سفرەکانی سەرەتا، ناوی کوردی/quote/newline، بڕی گەورە/کەرتی، formula escaping، سنووری قەبارە، پاکبوونەوەی transaction و وەڵامی کۆنی ڕووکار دەگرنەوە. داتای تاقیکردنەوە تەنها لە داتابەیسی کاتییە. پشکنینی بینراوی داگرتن لە وێبگەڕ، کردنەوەی Excel و Windows ـی ڕاستەقینە هێشتا نەکراون.
