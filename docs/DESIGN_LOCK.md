# دیزاینی قوفڵکراو 🔒

پەسەندی بەکارهێنەر: شاشەی سەرەتا بە ٦ کارتی سەرەکی.
دەستپێکردنی بنیادنانی سیستەم ڕێگەپێدراوە؛ گۆڕینی شێوازی پەسەندکراو ڕێگەپێدراو نییە.

| کارت | بەشەکان |
|---|---|
| ماڵەوە | داشبۆرد |
| فرۆشتن | کاشێر؛ پسوولە و گەڕاندنەوە |
| کاڵا و کۆگا | کاڵا و بارکۆد؛ کۆگا؛ کڕین؛ دابینکەر |
| کڕیار و قەرز | کڕیار؛ قەرز و پارەدانەوە |
| دارایی و ڕاپۆرت | سندوق و شەفت؛ خەرجی؛ ڕاپۆرت |
| بەڕێوەبردن | کارمەند و دەسەڵات؛ داتا و باکئەپ؛ ڕێکخستن |

`design/approved-card-home.html` وەشانی ڕەسەنی پەسەندکراوە.
`design/manifest.json` ناسنامەی SHA-256 ـی ئەو وەشانە هەڵدەگرێت.
`node scripts/verify-design.mjs` یەکسانییەکە دەپشکنێت.

نەخشەی بەشەکان و ڕووکار پەسەندکراون؛ تایبەتمەندییە پێشنیارکراوەکان هەمووی جێبەجێ نەکراون.
