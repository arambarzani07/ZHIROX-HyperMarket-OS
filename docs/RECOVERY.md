# ئامادەکردنی گەڕاندنەوە — 0.9.0

ئەم ڕێڕەوە کۆپێیەکی جیا بۆ پشکنینی گەڕاندنەوە دروست دەکات. داتابەیسی کارکردن ناگۆڕێت، سێرڤەر ناوەستێنێت و کۆپێکە خۆکار ناکاتە داتای سەرەکی.

## ئامادەکردن

باکئەپێکی تەواوبووی SQLite ـی ZHIROX هەڵبژێرە کە هەژماری خاوەنی چالاکی تێدایە. فایلەکانی سیستەمی کۆن، SQL Server `.bak` یان داتابەیسی چالاک بەکارمەهێنە. تۆمارەکانی دوای کاتی باکئەپ لەو کۆپێیەدا نابن. سەرەتا [پشکنینی باکئەپ](BACKUPS.md) ئەنجام بدە.

لە فۆڵدەری وەشانە نوێیەکە، بە Node.js 24+:

```powershell
npm run recovery:prepare -- --backup "C:\ZHIROX-Backups\chosen-backup.sqlite" --output "C:\ZHIROX-Recovery-Review"
```

ناونیشانەکان نموونەن؛ بە ڕێڕەوی تەواوی خۆت بیانگۆڕە. فۆڵدەری ئامانج دەبێت پێشتر نەبێت، لە داتای چالاک جیا بێت و نە لە ناوی بێت نە داتای چالاک لە ناوی بێت. ئەگەر داتای کارکردن بە `ZHIROX_DATA_DIR` دیاری کراوە، هەمان بەها بۆ ئەم فرمانەش بهێڵەوە. لە ناو ریپۆ تەنها `recovery/` ڕێگەپێدراوە و لە Git دەرکراوە.

## ئەنجام

- `zhirox.sqlite`: کۆپێی ئامادەکراو؛ کاڵا، فرۆشتن، ledger، سەبەتە و outbox دەپارێزێت.
- `recovery-report.json`: کاتی ئامادەکردن، ناوی باکئەپ، SHA-256 ـی سەرچاوە و کۆپێی کۆتایی، ژمارەی تۆمار و دانیشتنە هەڵوەشاوەکان.
- هەژمار و hash ـی وشەی نهێنی پارێزراون؛ وشەی نهێنی نوێ دروست ناکرێت. دانیشتنە کۆنەکان تەنها لە کۆپێکە هەڵدەوەشێنەوە، بۆیە چوونەژوورەوەی ئاسایی پێویستە. کردارێکی `recovery.prepared` لە تۆماری دەستگەیشتن زیاد دەبێت.
- `sync-device.json` کۆپی ناکرێت؛ کۆپێکە بێ هاوکاتکردنی کلاود ئامادە دەبێت.

SQLite integrity، foreign keys، خانە پێویستەکانی وەشانی ئێستا و بوونی یەک خاوەنی چالاک دەپشکنرێن. hash ـی سەرچاوە پێش/دوای کۆپیکردن بەراورد دەکرێت. ناوەڕۆکی خشتە پارێزراوەکان و تۆماری پێشووی دەستگەیشتن پێش/دوای هەڵوەشاندنەوەی دانیشتنەکان بەراورد دەکرێن. لە شکستی ئاساییدا تەنها فۆڵدەری نوێی دروستکراو پاک دەکرێتەوە؛ فایلی سەرچاوە و ئامانجێکی پێشتر هەبوو دەستکاری ناکرێن.

## پشکنینی کۆپێ بە جیا

دوای پێداچوونەوەی ڕاپۆرت، دەتوانرێت کۆپێکە لە پەنجەرەی PowerShell ـێکی جیا و پۆرتێکی جیا بکرێتەوە:

```powershell
$env:ZHIROX_DATA_DIR = "C:\ZHIROX-Recovery-Review"
$env:PORT = "3188"
npm start
```

`http://127.0.0.1:3188` بکەرەوە، بە هەژماری پێشووت بچۆ ژوورەوە و پسوولە، کۆگا و سەبەتەکان بپشکنە. ئەم سێرڤەرە بۆ پشکنینی کۆپێکەیە؛ فرۆشتنی مارکێت بۆی مەگوازەوە تا پلانی گۆڕینی داتای سەرەکی بە جیا پشتڕاست نەکراوەتەوە. فرمانەکە خۆی هیچ گۆڕینێکی سەرەکی ئەنجام نادات.

ناسنامەی کلاودی پێشوو بە جیا لە شوێنی پارێزراو هەڵبگرە. باکئەپێکی کۆن ڕەنگە لە checkpoint ـی کلاود دوا کەوتبێت؛ پێش چارەسەرکردنی ئەو جیاوازییە `sync-device.json` مەگوازەوە و `sync:prepare` بۆ ئەم داتابەیسە پێشتر پەیوەستکراوە دووبارە مەکەوە. گەڕاندنەوە/داگرتنی داتای کلاود جێبەجێ نەکراوە.

## سنوور و تاقیکردنەوە

فایلەکان داتای تایبەت و hash ـی وشەی نهێنی هەڵدەگرن و encryption نین؛ بە دەرەوە بڵاویان مەکەرەوە. SHA-256 یەکسانیی بایتەکان دەپشکنێت، سەرچاوەی متمانەپێکراو یان تۆماربوونی هەموو مامەڵە ڕاستەقینەکان ناسەلمێنێت. پشکنینی schema بەڵێنی سازگاریی هەموو وەشانە داهاتووەکان نییە.

٥٣ تاقیکردنەوەی پڕۆژە لە Linux/Node 24 تێپەڕین، لەوانە پاراستنی بایتەکانی سەرچاوە/داتای چالاک، ڕەتکردنەوەی فۆڵدەری هەبوو و symlink، باکئەپی خراب/ناگونجاو، trigger ـی گۆڕینی داتای پارێزراو، فرمانی CLI و کردنەوەی کۆپێ بە HTTP بەبێ کلاود. گەڕاندنەوەی ڕاستەقینەی مارکێت، گۆڕینی خۆکاری داتای سەرەکی، ڕووکاری restore، Windows و ئامێرەکان هێشتا تاقی نەکراونەوە/تەواو نەکراون.
