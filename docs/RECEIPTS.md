# مێژووی پسوولەکان — 0.5.0

لە کارتی فرۆشتن → پسوولە و گەڕاندنەوە، پسوولە تۆمارکراوەکانی SQLite پیشان دەدرێن. ئەم قۆناغە خوێندنەوە و چاپکردنەوەیە؛ گەڕاندنەوە، هەڵوەشاندنەوە و دەستکاریی پسوولە هێشتا جێبەجێ نەکراون.

- خاوەن و بەڕێوەبەر هەموو پسوولەکان دەبینن؛ کاشێر تەنها پسوولەکانی خۆی. کارمەندی کۆگا دەسەڵاتی ئەم بەشەی نییە. پشکنین لە سێرڤەرە، نە تەنها ڕووکار.
- گەڕان بە ژمارەی تەواوی پسوولە یان بەشێک لە ناوی کاڵای تۆمارکراوی ناو پسوولە. ژمارەی ئینگلیزی، عەرەبی و کوردی پەسەند دەکرێن. گۆڕینی ناوی کاڵای ئێستا مێژووی ناوی کاڵای فرۆشراو ناگۆڕێت.
- فلتەری IQD/USD و بەرواری سەرەتا/کۆتایی. هەردوو ڕۆژی هەڵبژێردراو بە تەواوی هەژمار دەکرێن بە کاتی عێراق UTC+03:00؛ مەودای بەروار 2000–9998 ـە. کۆی دینار و دۆلار لەگەڵ یەک کۆ ناکرێتەوە.
- هەر جار ٢٥ پسوولە؛ «پسوولەی زیاتر» پەڕەی داهاتوو دەخوێنێتەوە. ڕیزبەندی بە ژمارەی پسوولەی دابەزێنەرە، تا لە کاتی تۆماربوونی فرۆشتنی نوێدا پەڕەکانی کۆن دووبارە نەبنەوە. «نوێکردنەوە» لیستەکە لە نوێترین پسوولە دەست پێ دەکاتەوە.
- «وردەکاری و چاپ» پسوولەی پارێزراو دەکاتەوە بۆ چاپی وێبگەڕ؛ فرۆشتن، کۆگا و outbox ناگۆڕێت. پڕینتەری ڕاستەقینە هێشتا تاقی نەکراوەتەوە.

## چاپی پسوولەی کوردی — قۆناغی QA 0.27.0-dev.0

وردەکاریی پسوولەی فرۆشتن لە 58mm/80mm بە کوردی سۆرانی RTL دەپێشبینرێت و تەنها کرتەی بەکارهێنەر Print dialog دەکاتەوە. هەموو بڕەکان بە IQD یان USD cents ـی دروست دەپشکنرێنەوە؛ ناوی کاڵا HTML-escape دەکرێت و پسوولەی کۆی نادروست Print action نییە. هیچ چاپی خۆکار، Drawer Pulse، ESC/POS یان گۆڕینی هاردوێر جێبەجێ نەکراوە. CSS پانی ناوەڕۆکە، نە قەبارەی فیزیکی ڕۆڵی پڕینتەر. [ڕێنمایی QA](PRINT_QA.md).

## API و پاراستن

`GET /api/receipts?q=&from=&to=&currency=&before=&limit=`. limit لە ١ تا ٥٠ ـە؛ بنەڕەت ٢٥. وەڵام: `receipts`, `has_more`, `next_before`. هەر پسوولەیەک تەنها id، ژمارە، دراو، کۆ، پارەی وەرگیراو، بەروار و ناوی کاشێر هەڵدەگرێت. تێچوو، request payload، password و session ناگەڕێندرێنەوە.

actor لە دانیشتنی پشتڕاستکراو وەردەگیرێت؛ actor_id ـی نێردراوی کاشێر ناتوانێت دەسەڵات فراوان بکات. endpoint ـی وردەکاریی `/api/receipts/:id` هەمان سنووری خاوەندارێتی دەپشکنێت. پسوولەکانی کۆن بەبێ actor تەنها بۆ خاوەن/بەڕێوەبەر دەردەکەون.

پشکنینەکان: دەسەڵاتی هەموو/تایبەت، منعکردنی warehouse/بێ‌دانیشتن، actor spoofing، ژمارەکانی ١ و ۱، ناوی مێژوویی، SQL injection، دراو، سنووری نیوەشەو لە عێراق، بەرواری نادروست، keyset pagination لەگەڵ فرۆشتنی نوێ، و query ـی درێژ/نادروست. ٣٤ تاقیکردنەوەی پڕۆژە سەرکەوتوون و checksum ـی دیزاینی قوفڵکراو نەگۆڕاوە.

لە HTTP و SQLite تاقی کراوەتەوە؛ پشکنینی بینراوی ئەم شاشەیە دوای چوونەژوورەوە لە وێبگەڕ و Windows/پڕینتەری ڕاستەقینە لەم قۆناغەدا نەکراون. هیچ داتای نمایشی لە داتابەیسی مارکێت دانەنراوە.
