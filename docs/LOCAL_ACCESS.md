# دەستگەیشتنی ناوخۆ — 0.8.0

هیچ هەژمار یان وشەی نهێنییەکی ئامادە نییە. یەکەم کردنەوە هەژماری خاوەن درووست دەکات.
تەنها یەک خاوەن هەیە. خاوەن دەتوانێت کارمەندی manager، cashier یان warehouse درووست بکات.
فۆڕمی خاوەن هەمان ڕەنگ، فۆنت و شێوازی پەنجەرەی دیزاینی قوفڵکراو بەکاردەهێنێت؛ شاشەی ٦ کارت نەگۆڕاوە.

| ڕۆڵ | دەسەڵاتی کارای ئێستا |
|---|---|
| خاوەن | کاڵا و کۆگا، فرۆشتن، هەموو پسوولەکان، ڕاپۆرتی فرۆشتن، هاوکاتکردن، کارمەند، تۆماری دەسەڵات و دروستکردن/داگرتن/پشکنینی باکئەپ |
| بەڕێوەبەر | کاڵا و کۆگا، فرۆشتن، هەموو پسوولەکان، ڕاپۆرتی فرۆشتن و API ـی تۆماری دەسەڵات |
| کاشێر | کاڵا و کۆگا بەبێ نرخی کڕین، فرۆشتن و پسوولەی خۆی |
| کارمەندی کۆگا | خوێندنەوە و تۆمارکردنی کاڵا و خوێندنەوەی کۆگا |

## پاراستن

- Scrypt: N=32768، r=8، p=3؛ salt ـی هەڕەمەکی ١٦ بایت. پاسۆرد بە دەقی ڕوون ناپارێزرێت.
- Session ـی هەڕەمەکی ٣٢ بایت؛ تەنها SHA-256 ـی token لە داتابەیس هەڵدەگیرێت.
- Cookie: HttpOnly، SameSite=Strict، host-only، Path=/؛ کۆتایی دوای ١٢ کاتژمێر.
- CSRF ـی تایبەت بە دانیشتن بۆ کردارە گۆڕانکارییەکان؛ پشکنینی Origin/Host و JSON.
- دوای ٥ هەوڵی هەڵە لە خولەکێک، ئەو ناوی چوونەژوورەوەیە بۆ یەک خولەک ڕادەگیرێت.
- گۆڕینی ڕۆڵ یان چالاکیی حساب هەموو دانیشتنەکانی ئەو کارمەندە کۆتایی پێدەهێنێت.
- خاوەن لە ڕووکارەکە ناچالاک ناکرێت و ڕۆڵەکەی ناگۆڕدرێت.
- Audit ـی گۆڕانکاریی دەستگەیشتن هەڵدەگیرێت؛ وشەی نهێنی و token تێدا نییە.
- تێچووی کاڵا لە API ـی کاشێر ناگەڕێتەوە؛ پسوولەکانی بەکارهێنەرێکی تر بۆی داخراون.
- فرۆشتنە نوێکان بە ناسنامەی کارمەند پەیوەستن. پسوولە پێشووە بێ ناسنامەکان تەنها بۆ خاوەن/بەڕێوەبەرن.

## سنووری ئێستا

ئەم وەشانە لە loopback ـی کۆمپیوتەری ناوخۆ بە HTTP کار دەکات. Cookie ـی Secure لە ئەم ڕێڕەوەدا دانەنراوە.
ئەمە ڕێکخستنی LAN یان خزمەتگوزارییەکی ئینتەرنێتی نییە. فایلەکانی داتابەیس و باکئەپ هێشتا پێویستیان بە پاراستنی کۆمپیوتەر و دیسک هەیە.
ڕۆڵەکان تەنها ئەو کردارە کارایانە کۆنترۆڵ دەکەن کە ئێستا هەن؛ بەشەکانی داهاتوو دەبێت دەسەڵاتی خۆیان زیاد بکەن.
گۆڕین/ڕیسێتکردنی پاسۆرد، MFA، گەڕاندنەوەی حساب و بەڕێوەبردنی session لە چەند ئامێر هێشتا جێبەجێ نەکراون.

## پشکنین

`npm run check` و `npm test`؛ ٤٩ تاقیکردنەوە سەرکەوتوون.
HTTP tests دەستگەیشتنی بێ login، CSRF، دەسەڵاتی ڕۆڵ، نرخی کڕینی نهێنی، خاوەندارێتی پسوولە و کۆتایی دانیشتن دەپشکنن.
Browser QA تەنها بینراویی فۆڕمی ڕێکخستنی یەکەمی خاوەن پشتڕاست دەکاتەوە؛ زانیاریی چوونەژوورەوەی بەکارهێنەر بەکار نەهاتووە.
