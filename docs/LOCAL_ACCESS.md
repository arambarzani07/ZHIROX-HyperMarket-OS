# دەستگەیشتنی ناوخۆ — 0.11.0

هیچ هەژمار یان وشەی نهێنییەکی ئامادە نییە. یەکەم کردنەوە هەژماری خاوەن درووست دەکات.
تەنها یەک خاوەن هەیە. خاوەن دەتوانێت کارمەندی manager، cashier یان warehouse درووست بکات.
فۆڕمی خاوەن هەمان ڕەنگ، فۆنت و شێوازی پەنجەرەی دیزاینی قوفڵکراو بەکاردەهێنێت؛ شاشەی ٦ کارت نەگۆڕاوە.

| ڕۆڵ | دەسەڵاتی کارای ئێستا |
|---|---|
| خاوەن | کاڵا و کۆگا، فرۆشتن، هەموو پسوولەکان، ڕاپۆرتی فرۆشتن، هاوکاتکردن، کارمەند، تۆماری دەسەڵات و دروستکردن/داگرتن/پشکنینی باکئەپ |
| بەڕێوەبەر | کاڵا و کۆگا، فرۆشتن، هەموو پسوولەکان، ڕاپۆرتی فرۆشتن و API ـی تۆماری دەسەڵات |
| کاشێر | کاڵا و کۆگا بەبێ نرخی کڕین، فرۆشتن و پسوولەی خۆی |
| کارمەندی کۆگا | خوێندنەوە و تۆمارکردنی کاڵا و خوێندنەوەی کۆگا |

## پاراستن

- Scrypt: N=32768، r=8، p=3؛ salt ـی هەڕەمەکی ١٦ بایت. پاسۆرد بە دەقی ڕوون ناپارێزرێت.
- Session ـی هەڕەمەکی ٣٢ بایت؛ تەنها SHA-256 ـی token لە داتابەیس هەڵدەگیرێت.
- Cookie: HttpOnly، SameSite=Strict، host-only، Path=/؛ کۆتایی دوای ١٢ کاتژمێر.
- CSRF ـی تایبەت بە دانیشتن بۆ کردارە گۆڕانکارییەکان؛ پشکنینی Origin/Host و JSON.
- دوای ٥ هەوڵی هەڵە لە خولەکێک، ئەو ناوی چوونەژوورەوەیە بۆ یەک خولەک ڕادەگیرێت.
- گۆڕینی ڕۆڵ یان چالاکیی حساب هەموو دانیشتنەکانی ئەو کارمەندە کۆتایی پێدەهێنێت.
- خاوەن لە ڕووکارەکە ناچالاک ناکرێت و ڕۆڵەکەی ناگۆڕدرێت.
- Audit ـی گۆڕانکاریی دەستگەیشتن هەڵدەگیرێت؛ وشەی نهێنی و token تێدا نییە.
- تێچووی کاڵا لە API ـی کاشێر ناگەڕێتەوە؛ پسوولەکانی بەکارهێنەرێکی تر بۆی داخراون.
- فرۆشتنە نوێکان بە ناسنامەی کارمەند پەیوەستن. پسوولە پێشووە بێ ناسنامەکان تەنها بۆ خاوەن/بەڕێوەبەرن.

## سنووری ئێستا

ئەم وەشانە لە loopback ـی کۆمپیوتەری ناوخۆ بە HTTP کار دەکات. Cookie ـی Secure لە ئەم ڕێڕەوەدا دانەنراوە.
ئەمە ڕێکخستنی LAN یان خزمەتگوزارییەکی ئینتەرنێتی نییە. فایلەکانی داتابەیس و باکئەپ هێشتا پێویستیان بە پاراستنی کۆمپیوتەر و دیسک هەیە.
ڕۆڵەکان تەنها ئەو کردارە کارایانە کۆنترۆڵ دەکەن کە ئێستا هەن؛ بەشەکانی داهاتوو دەبێت دەسەڵاتی خۆیان زیاد بکەن.
ڕیسێتکردنی پاسۆرد بەبێ زانینی وشەی ئێستا، MFA، گەڕاندنەوەی حساب و بەڕێوەبردنی session لە چەند ئامێر هێشتا جێبەجێ نەکراون.

## پشکنین

`npm run check` و `npm test`؛ ٦٧ تاقیکردنەوە سەرکەوتوون.
HTTP tests دەستگەیشتنی بێ login، CSRF، دەسەڵاتی ڕۆڵ، نرخی کڕینی نهێنی، خاوەندارێتی پسوولە و کۆتایی دانیشتن دەپشکنن.
Browser QA تەنها بینراویی فۆڕمی ڕێکخستنی یەکەمی خاوەن پشتڕاست دەکاتەوە؛ زانیاریی چوونەژوورەوەی بەکارهێنەر بەکار نەهاتووە.

## گۆڕینی وشەی نهێنی — 0.11.0

هەر ڕۆڵێک لە دوگمەی «گۆڕینی وشەی نهێنی» لە تەنیشت ناوی هەژمارەکەی دەتوانێت وشەی خۆی بگۆڕێت. وشەی ئێستا، وشەی نوێ و دووبارەکردنەوەی وشەی نوێ بنووسە؛ وشەی نوێ دەبێت ١٢ تا ١٢٨ پیت و لە وشەی ئێستا جیاواز بێت. پێش دەستپێکردن، پاشەکەوتکردنی سەبەتە یان ئەنجامی فرۆشتنی نادیار پشتڕاست بکەرەوە.

گۆڕین، سڕینەوەی هەموو دانیشتنەکانی ئەو هەژمارە و تۆماری `user.password_changed` لە یەک transaction ـدا ئەنجام دەدرێن. هەژمارەکانی تر، ڕۆڵ، سەبەتە، کاڵا و فرۆشتن ناگۆڕدرێن. دوای سەرکەوتن هەژمارەکە دەچێتە دەرەوە؛ بە وشەی نوێ بچۆ ژوورەوە. گۆڕینی وشەی کەسێکی تر، تەنانەت بۆ خاوەن، لەم کردارەدا نییە.

`POST /api/auth/password` بە JSON ـی `{current_password,new_password}` دانیشتنی چالاک و CSRF پێویستە. ناسنامەی هەژمار لە دانیشتن وەردەگیرێت، نە لە payload. وشە، salt، hash و token لە وەڵام و audit نین. هەوڵی هەڵە لە وشەی ئێستا هەمان ژمێرەری پارێزراوی چوونەژوورەوە بەکاردەهێنێت: دوای ٥ هەوڵ لە خولەکێک، یەک خولەک ڕاگرتن. دوای دەرچوون، گۆڕینی ڕۆڵ، کۆتایی دانیشتن یان گۆڕانێکی هاوکات، داواکاریی کۆن ناتوانێت وشەکە بنووسێتەوە.

فۆڕم لە داخستن، گواستنەوەی بەش یان گۆڕینی دانیشتن پاک دەکرێتەوە. ئەگەر پەیوەندی پچڕا و ئەنجامی گۆڕین نادیار بوو، پەڕەکە نوێ بکەرەوە و چوونەژوورەوە بە وشەی نوێ تاقی بکەرەوە؛ ئەگەر گۆڕین ئەنجام نەدرابوو، وشەی کۆن هێشتا کار دەکات. هیچ وشەیەک لە چات، Git یان localStorage دانانرێت.

گۆڕین ناوخۆییە و بۆ کلاود نانێردرێت. باکئەپە پێشووەکان hash ـی وشەی ئەو کاتەیان تێدایە؛ ئامادەکردنی گەڕاندنەوەی باکئەپی کۆن هەمان وشەی کۆنی دەوێت. گەڕاندنەوەی حسابی ونبوو یان reset بەبێ وشەی ئێستا هێشتا جێبەجێ نەکراوە.

پشکنینە نوێکان: هەموو ڕۆڵەکان، هەڵوەشاندنەوەی هەموو دانیشتنەکانی خۆ و پاراستنی هەژماری تر، هەوڵی هەڵە/سنووردارکردن، گۆڕینی هاوکات، دەرچوون لە کاتی hashing، rollback لە شکستی audit، چوونەژوورەوەی هاوکات بە وشەی کۆن، HTTP/CSRF/Origin و پشتگوێخستنی وەڵامی کۆنی ڕووکار. تاقیکردنەوەی بینراوی فۆڕمی گۆڕین لە وێبگەڕی ڕاستەقینە هێشتا نەکراوە.
