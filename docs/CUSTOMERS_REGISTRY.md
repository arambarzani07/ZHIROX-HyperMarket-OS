# ZHIROX — کڕیاران: تۆماری ڕاستەقینەی SQLite

**دۆخ:** گەشەپێدانی ناوەڕۆکی سیستەم؛ نە Build، نە Deploy، نە Production.

## چی جێبەجێ کرا
- `src/customers.mjs`: خشتەی `customers`ی ناوخۆی SQLite، کۆدی یەکتای کڕیار، ناو، تەلەفۆن، دراو، سنووری هەژمار، دۆخی چالاک/ڕاگیراو و ژمارەی وەشان.
- `/api/customers`ی GET و POST، `/api/customers/:id`ی GET و PATCH. POST یەکتایی `request_id` هەیە و دووبارە ناردنی هەمان داواکاری کڕیاری دووەم دروست ناکات.
- ئەگەر دوو بەکارهێنەر هەمان کڕیار دەستکاری بکەن، `revision`ی کۆن بە 409 ڕەت دەکرێتەوە؛ گۆڕانکاریی کەسێکی تر نانووسرێتەسەر.
- `customers.read`: خاوەن، بەڕێوەبەر، کاشێر. `customers.write`: تەنها خاوەن و بەڕێوەبەر. کارمەندی کۆگا دەستگەیشتنی بە کڕیار نییە.
- داتای پەیوەندی و سنووری هەژمار لە API ـی کاشێر بە تەواوی دەشاردرێنەوە؛ نەک تەنها لە CSS.
- گەڕان بە کۆد، ناو و تەلەفۆن، پەڕەبەندی بە کۆدی یەکتا و قەبارەی 25–100 تۆمار. ناوی دووبارە ڕێگەپێدراوە؛ کۆدی دووبارە ڕەت دەکرێتەوە.
- تۆمارکردنی Audit بۆ دروستکردن و گۆڕانکاری؛ سنووری هەژمار و چالاککردن/ڕاگرتن بە کۆن/نوێ تۆمار دەکرێن، بەڵام ژمارەی تەلەفۆن لە Audit ـدا دووبارە نابێتەوە.
- ڕووکاری سۆرانی RTL لە `public/customers.js` پەیوەست بە Backend ـە و لە هەمان بەشی کڕیاری دیزاینی شەش کارتی پەسەندکراودا دەرئەکەوێت.

## سنووری بەرنامە
**ئەمە هێشتا سیستەمی قەرز نییە.** `credit_limit` تەنها سنووری دیاریکراو بۆ داهاتووە؛ هیچ `debt`، `repayment`، `cash sale to credit` یان `automatic limit enforcement` ئەنجام نادرێت. پێش زیادکردنی قەرزی کارا، پێویستە Ledger ـی بێ‌گۆڕان، وەرگرتن/پارەدانەوە، مۆڵەت، هەژمارکردنی تەواوی دوو دراو و atomic checkout بە جیا تاقی بکرێنەوە.

هیچ کڕیارێک بۆ Supabase نانێردرێت؛ هیچ خشتەی داتابەیسی کۆنی SQL Server دەستکاری نەکراوە. داتا تەنها لە SQLite ـی تایبەتی ZHIROX پاشەکەوت دەبێت. سنووری پارە بە بچووکترین یەکەی دراو تۆمار دەبێت: IQD = دینار، USD = سێنت. کۆد و دراو دوای دروستکردن ناگۆڕدرێن؛ Delete API نییە.

## پشکنین
- `test/customers.test.mjs`: SQLiteی بەتاڵ، بەردەوامی دوای restart، یەکتایی کۆد، idempotency، RBAC و شاردنەوەی داتا، revision، audit، گەڕان و pagination.
- `test/customers-http.test.mjs`: ڕێڕەوی HTTP بە سێرڤەر و SQLite ـی موقەتی، هەژماری خاوەن/کاشێر، CSRF، 409 و پاراستنی داتای هەستیار.

**ماوە بۆ Production:** پشکنینی دەستی ڕووکار لە ژینگەی جیا و قەبارەی کڕیاری زۆر، Backup/Restore و Ledger ـی جیا بۆ قەرز. نە Merge، نە بڵاوکردنەوە، نە تاقیکردنەوە لە سیستەمی کۆن.
