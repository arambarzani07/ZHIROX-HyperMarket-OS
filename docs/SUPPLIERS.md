# دابینکەرەکان — 0.19.0

لە کاڵا و کۆگا → دابینکەر، خاوەن و بەڕێوەبەر دەتوانن دابینکەری ڕاستەقینە تۆمار بکەن. کارمەندی کۆگا تەنها لیست و پرۆفایل دەخوێنێتەوە؛ کاشێر ڕێگەی نییە. هەموو دەسەڵاتەکان لە سێرڤەر دەپشکنرێن، نەک تەنها لە شاردنەوەی دوگمە.

خانەکان: کۆدی دابینکەر، ناو، مۆبایل، ناونیشان و دراوی پێشنیارکراوی مامەڵە IQD/USD. ناو و کۆد پێویستن؛ مۆبایل و ناونیشان ئیختیارین. کۆد تا ٤٠ پیتی ئینگلیزی/ژمارە/. _ - و بە پیتی گەورە یەکدەست دەکرێت. هەر کۆد یەکتایە؛ ناو یان مۆبایلی هاوشێوە بە خۆکار یەکناخرێن.

گەڕان لە ناو، کۆد یان مۆبایل ئەنجام دەدرێت. هەر پەڕە ٢٥ ڕیز و ژمارەی کۆی ئەنجامەکان پیشان دەدات. پرۆفایل زانیاریی پەیوەندی و کاتی تۆمار بە کاتی عێراق پیشان دەدات. «دراوی پێشنیارکراو» هیچ باڵانس، قەرز یان نرخی ئاڵوگۆڕێک درووست ناکات.

## پاراستنی تۆمارکردن

هەر داواکاری `request_id` ـی جێگیر هەیە. تۆمارکردنی دابینکەر و audit ـی `supplier.created` لە یەک transaction ـدا ئەنجام دەدرێن. Audit تەنها ناسنامەی ئەنجامدەر و دابینکەر و کات هەڵدەگرێت؛ ناو/مۆبایل/ناونیشان دووبارە لە details دانانرێن. شکستی audit تۆمار و retry key هەڵدەوەشێنێتەوە.

ئەگەر وەڵام ون بوو یان هەڵەی 500 ڕوویدا، فۆڕم زانیارییەکان قوفڵ دەکات و «پشتڕاستکردنەوەی هەمان تۆمار» هەمان body و request_id دەنێرێتەوە. دووجار کلیک دوو داواکاری هاوکات نانێرێت. هەمان داواکاری بە هەمان هەژمار و زانیاری، دوای restart ـیش، هەمان دابینکەر دەگەڕێنێتەوە. هەژماری تر 403 و زانیاریی جیاواز 409 وەردەگرێت. کۆدی دووبارە بە request_id ـی نوێش 409 ـە.

داخستن یان گواستنەوە فۆڕم و زانیارییە کاتییەکانی پاک دەکاتەوە. داخستن داواکاریی تۆمارکردنی نێردراو هەڵناوەشێنێتەوە؛ ئەگەر ئەنجام نادیار بوو بە کۆدی دابینکەر بگەڕێ پێش تۆمارکردنی نوێ. زانیارییەکان لە localStorage دانانرێن.

## API

- `GET /api/suppliers?q=&after=&limit=`: دەسەڵاتی `suppliers.read`، گەڕان تا ١٠٠ پیت، limit لە ١ تا ٥٠ (بنەڕەت ٢٥)، cursor بە code. وەڵام: suppliers، total، has_more، next_after. کۆ و ڕیزەکانی هەر وەڵام لە یەک snapshot دەخوێندرێنەوە.
- `GET /api/suppliers/:id`: پرۆفایلی دابینکەر، بە هەمان دەسەڵاتی خوێندنەوە.
- `POST /api/suppliers`: `suppliers.write`، JSON، دانیشتن و CSRF پێویستە. خانەکان request_id، code، name، phone، address، currency ـن؛ خانەی زیادە، لەوانە opening_balance، ڕەت دەکرێتەوە. دوای خوێندنەوەی body دانیشتن دووبارە دەپشکنرێت.

هیچ actor_id، request_id یان fingerprint ـێک لە لیست و پرۆفایلی وەڵامدا نییە. ڕیزبەندی بە code و cursor ـە؛ هەر داواکاری snapshot ـی نوێیە و لە کاتی تۆمارکردنی نوێدا کۆی ئەنجامەکان دەکرێت بگۆڕێت. نوێکردنەوە لە پەڕەی یەکەم دەست پێ دەکاتەوە.

## باکئەپ، کلاود و سنوور

دابینکەر لە SQLite ـی ناوخۆ و باکئەپە کاتژمێرییەکان هەڵدەگیرێت؛ پشکنینی گەڕاندنەوە هەموو ڕیزەکان و retry identity پارێزراو دەهێڵێتەوە. لەم وەشانەدا دابینکەر بۆ Supabase نانێردرێت؛ هاوکاتکردنی v1 هەر کاڵا/فرۆشتن/جووڵەی کۆگایە. تۆمارکردنی دابینکەر outbox یان کۆگای کاڵا ناگۆڕێت.

کڕین، پسوولەی دابینکەر، قەرز، پارەدان، باڵانس، دەستکاری و سڕینەوەی دابینکەر هێشتا جێبەجێ نەکراون. ژمارەی سفر یان داتای نمایشی بۆ حسابەکان دانانراوە. دیزاینی قوفڵکراوی ٦ کارت و ١٥ بەش نەگۆڕاوە؛ کارکردنی ڕاستەقینە لە بەشی دابینکەری پێشوو زیاد کراوە.

١٤٤ تاقیکردنەوە و design checksum تێپەڕین. پشکنینی دەسەڵات/CSRF و HTTP، retry ـی هاوکات و دوای restart، conflict، rollback ـی audit، گەڕان/پەڕەبەندی، HTML escaping، فۆڕمی نادیار/دووبارەهەوڵدانەوە، پاککردنەوەی زانیاری دوای داخستن و مانەوەی دابینکەر لە باکئەپ/گەڕاندنەوە سەرکەوتوون. هیچ دابینکەری تاقیکردنەوە لە داتابەیسی کارکردن دانەنراوە. پشکنینی بینراوی فۆڕمی چووەژوورەوە و Windows هێشتا ماون.
