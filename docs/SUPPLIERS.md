# دابینکەرەکان — 0.20.0

لە کاڵا و کۆگا → دابینکەر، خاوەن و بەڕێوەبەر دەتوانن دابینکەری ڕاستەقینە تۆمار بکەن و زانیارییەکانی دەستکاری بکەن. کارمەندی کۆگا تەنها لیست و پرۆفایل دەخوێنێتەوە؛ کاشێر ڕێگەی نییە. هەموو دەسەڵاتەکان لە سێرڤەر دەپشکنرێن، نەک تەنها لە شاردنەوەی دوگمە.

خانەکان: کۆدی دابینکەر، ناو، مۆبایل، ناونیشان و دراوی پێشنیارکراوی مامەڵە IQD/USD. ناو و کۆد پێویستن؛ مۆبایل و ناونیشان ئیختیارین. کۆد تا ٤٠ پیتی ئینگلیزی/ژمارە/. _ - و بە پیتی گەورە یەکدەست دەکرێت. هەر کۆد یەکتایە؛ ناو یان مۆبایلی هاوشێوە بە خۆکار یەکناخرێن.

گەڕان لە ناو، کۆد یان مۆبایل ئەنجام دەدرێت. هەر پەڕە ٢٥ ڕیز و ژمارەی کۆی ئەنجامەکان پیشان دەدات. پرۆفایل زانیاریی پەیوەندی و کاتی تۆمار بە کاتی عێراق پیشان دەدات. «دراوی پێشنیارکراو» هیچ باڵانس، قەرز یان نرخی ئاڵوگۆڕێک درووست ناکات.

## پاراستنی تۆمارکردن

هەر داواکاری `request_id` ـی جێگیر هەیە. تۆمارکردنی دابینکەر و audit ـی `supplier.created` لە یەک transaction ـدا ئەنجام دەدرێن. Audit تەنها ناسنامەی ئەنجامدەر و دابینکەر و کات هەڵدەگرێت؛ ناو/مۆبایل/ناونیشان دووبارە لە details دانانرێن. شکستی audit تۆمار و retry key هەڵدەوەشێنێتەوە.

ئەگەر وەڵام ون بوو یان هەڵەی 500 ڕوویدا، فۆڕم زانیارییەکان قوفڵ دەکات و «پشتڕاستکردنەوەی هەمان تۆمار» هەمان body و request_id دەنێرێتەوە. دووجار کلیک دوو داواکاری هاوکات نانێرێت. هەمان داواکاری بە هەمان هەژمار و زانیاری، دوای restart ـیش، هەمان دابینکەر دەگەڕێنێتەوە. هەژماری تر 403 و زانیاریی جیاواز 409 وەردەگرێت. کۆدی دووبارە بە request_id ـی نوێش 409 ـە.

داخستن یان گواستنەوە فۆڕم و زانیارییە کاتییەکانی پاک دەکاتەوە. داخستن داواکاریی تۆمارکردنی نێردراو هەڵناوەشێنێتەوە؛ ئەگەر ئەنجام نادیار بوو بە کۆدی دابینکەر بگەڕێ پێش تۆمارکردنی نوێ. زانیارییەکان لە localStorage دانانرێن.

## API

- `GET /api/suppliers?q=&after=&limit=`: دەسەڵاتی `suppliers.read`، گەڕان تا ١٠٠ پیت، limit لە ١ تا ٥٠ (بنەڕەت ٢٥)، cursor بە code. وەڵام: suppliers، total، has_more، next_after. کۆ و ڕیزەکانی هەر وەڵام لە یەک snapshot دەخوێندرێنەوە.
- `GET /api/suppliers/:id`: پرۆفایلی دابینکەر، بە هەمان دەسەڵاتی خوێندنەوە.
- `POST /api/suppliers`: `suppliers.write`، JSON، دانیشتن و CSRF پێویستە. خانەکان request_id، code، name، phone، address، currency ـن؛ خانەی زیادە، لەوانە opening_balance، ڕەت دەکرێتەوە. دوای خوێندنەوەی body دانیشتن دووبارە دەپشکنرێت.

هیچ actor_id، request_id یان fingerprint ـێک لە لیست و پرۆفایلی وەڵامدا نییە. ڕیزبەندی بە code و cursor ـە؛ هەر داواکاری snapshot ـی نوێیە و لە کاتی تۆمارکردنی نوێدا کۆی ئەنجامەکان دەکرێت بگۆڕێت. نوێکردنەوە لە پەڕەی یەکەم دەست پێ دەکاتەوە.

## باکئەپ، کلاود و سنوور

دابینکەر لە SQLite ـی ناوخۆ و باکئەپە کاتژمێرییەکان هەڵدەگیرێت؛ پشکنینی گەڕاندنەوە هەموو ڕیزەکان و retry identity پارێزراو دەهێڵێتەوە. لەم وەشانەدا دابینکەر بۆ Supabase نانێردرێت؛ هاوکاتکردنی v1 هەر کاڵا/فرۆشتن/جووڵەی کۆگایە. تۆمارکردنی دابینکەر outbox یان کۆگای کاڵا ناگۆڕێت.

کڕین، پسوولەی دابینکەر، قەرز، پارەدان، باڵانس و سڕینەوەی دابینکەر هێشتا جێبەجێ نەکراون. ژمارەی سفر یان داتای نمایشی بۆ حسابەکان دانانراوە. دیزاینی قوفڵکراوی ٦ کارت و ١٥ بەش نەگۆڕاوە؛ کارکردنی ڕاستەقینە لە بەشی دابینکەری پێشوو زیاد کراوە.

١٥٧ تاقیکردنەوە و design checksum تێپەڕین. پشکنینی دەسەڵات/CSRF و HTTP، retry ـی هاوکات و دوای restart، conflict، rollback ـی audit، گەڕان/پەڕەبەندی، HTML escaping، فۆڕمی نادیار/دووبارەهەوڵدانەوە، پاککردنەوەی زانیاری دوای داخستن و مانەوەی دابینکەر لە باکئەپ/گەڕاندنەوە سەرکەوتوون. هیچ دابینکەری تاقیکردنەوە لە داتابەیسی کارکردن دانەنراوە. پشکنینی بینراوی فۆڕمی چووەژوورەوە و Windows هێشتا ماون.

## دەستکاریی پارێزراو — 0.20.0

لە پرۆفایل «دەستکاریی زانیاری» بکە. سەرەتا نوێترین زانیاری لە سێرڤەر دەخوێندرێتەوە؛ ناو، مۆبایل، ناونیشان و دراوی پێشنیارکراو دەگۆڕدرێن. کۆدی دابینکەر، ناسنامە و کاتی دروستکردن جێگیرن. ژمارەی وەشان و کاتی نوێکردنەوە لە پرۆفایل دیارن. گۆڕینی دراوی پێشنیارکراو هیچ مامەڵە یان باڵانسێک ناگۆڕێت.

`PATCH /api/suppliers/:id` دەسەڵاتی `suppliers.write` و JSON/CSRF/دانیشتن دەوێت؛ دوای body دانیشتن دووبارە دەپشکنرێتەوە. body: request_id، revision، name، phone، address، currency. revision ژمارەی تەواوی وەشانی خوێندراوە؛ code و خانە دارایییەکان ڕەت دەکرێنەوە. لە هەر دەستکاریی ڕاستەقینەدا revision یەک زیاد دەبێت. وەشانی کۆن 409 وەردەگرێت، فۆڕم قوفڵ دەبێت و دوگمەی «خوێندنەوەی زانیاریی نوێ» دەردەکەوێت. ئەو دوگمەیە دەستکاریی نەپاشەکەوتکراو دەسڕێتەوە و فۆڕم بە زانیاریی نوێ دەکاتەوە؛ هیچ merge یان overwrite ـی خۆکار نییە.

نوێکردنەوە، audit و ناسنامەی retry لە یەک transaction ـدان. Audit تەنها ناوی خانە گۆڕاوەکان و from_revision/to_revision هەڵدەگرێت؛ دەقی پێشووتر/نوێی ناو، مۆبایل و ناونیشان لێرە ناپارێزرێت. لە بەشی تۆماری کردارەکان ناوی خانە گۆڕاوەکان پیشان دەدرێت. ئەمە مێژووی تەواوی زانیاریی پەیوەندی یان undo نییە.

لە وەڵامی نادیاردا هەمان PATCH و request_id و revision دووبارە دەنێردرێنەوە. دووبارەهەوڵدانەوەی سەرکەوتوو هەرگیز دەستکارییەکی دواتر هەڵناوەشێنێتەوە؛ وەڵام supplier ـی ئێستا لەگەڵ `applied_revision` ـی داواکاریی سەرەتا دەدات. هەمان request_id بە هەژماری تر 403 و بە زانیاری/دابینکەری تر 409 ـە. داواکاریی بێ گۆڕانکاری revision و audit زیاد ناکات، بەڵام retry identity دەپارێزێت بۆ ئەوەی دواتر زانیارییەکان نەگەڕێنێتەوە.

داتابەیسی 0.19.0 بە زیادکردنی revision=1 و updated_at گەشە دەکرێت؛ هیچ contact، code، ID، fingerprint یان تۆماری پێشوو ناسڕدرێتەوە. بۆ تۆماری کۆن، کاتی سەرەتایی نوێکردنەوە هەمان created_at ـە. دووبارەکردنەوەی migration گۆڕانکاریی زیادە ناکات. `supplier_changes` ناسنامەکانی retry هەڵدەگرێت و تۆمارەکانی نانووسرێنەوە/ناسڕدرێنەوە؛ باکئەپ و ئامادەکردنی گەڕاندنەوەش دەیانپارێزن. هیچ ناردنێک بۆ Supabase لەم قۆناغەدا نییە.

پشکنینە نوێکان: کێبڕکێی دوو editor و هەمان request ـی هاوکات لە HTTP، stale revision، audit و retry-marker rollback، replay دوای دەستکاریی دواتر و SQLite restart، no-op، migration ـی schema ـی کۆن، مانەوەی contact و retry لە باکئەپ/گەڕاندنەوە، PATCH ـی وردی ڕووکار، قوفڵکردنی conflict و نوێخوێندنەوەی ئاشکرا. هەموو ١٥٧ تاقیکردنەوە لە Linux/Node 24 تێپەڕین. Windows و پشکنینی بینراوی فۆڕمی چووەژوورەوە هێشتا ماون.
