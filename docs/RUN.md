# دەستپێکردن

## Windows

١. Node.js 24 یان نوێتر لە سەرچاوەی فەرمی دامەزرێنە.
٢. ریپۆکە دابەزێنە و فایلەکان دەربهێنە.
٣. سەرەتا `scripts/check-windows.cmd` بکەرەوە؛ پاش سەرکەوتنی پشکنین `scripts/start-windows.cmd` بکەرەوە.
٤. لە هەمان کۆمپیوتەر `http://127.0.0.1:3187` بکەرەوە.
٥. لە یەکەم کردنەوەدا، ناو، ناوی چوونەژوورەوە و وشەی نهێنیی خاوەن دیاری بکە. هەژمار و پاسۆردی ئامادە نییە.
٦. لە کارتی بەڕێوەبردن → کارمەند و دەسەڵات، کارمەند زیاد بکە.

ئەمە فایلێکی EXE یان دامەزرێنەری یەکجارەکی نییە؛ ئەوە قۆناغێکی دواترە.
بۆ بەردەوامبوونی کار و باکئەپی کاتژمێری، پەنجەرەی سێرڤەر مەخە.

## Linux / macOS

```sh
npm start
```

پێویستی بە npm install یان ئینتەرنێت نییە.

## پشکنین

```sh
npm run check
npm test
```

تاقیکردنەوەکان داتابەیسی کاتی درووست دەکەن و بە داتای مارکێت دەست نادەن.

## هاوکاتکردنی کلاود

کارکردنی ئۆفلاین بێ ناسنامەی کلاود بەردەوامە. بۆ چالاککردنی ئامێر، [SYNC.md](SYNC.md) ببینە. ڕێکخستنی ئامێر لە ئەم ژینگەیە تاقی کراوەتەوە؛ فایلە نهێنییەکان لە GitHub نین و کۆمپیوتەری Windows خۆکار ڕێک نەخراوە.

## شوێنی داتا لە Windows — 0.3.1

لە دامەزراندنی نوێدا: `%LOCALAPPDATA%\ZHIROX-HyperMarket-OS\data`. داتا و باکئەپ لە دەرەوەی فۆڵدەری وەشانەکە دەمێننەوە. سێرڤەر و ڕێکخستنی sync هەمان شوێن بەکاردەهێنن.

ئەگەر `data/zhirox.sqlite` یان `data/sync-device.json` لە وەشانی کۆندا هەبێت، هەمان فۆڵدەر بەکاردەهێنرێت؛ هیچ گواستنەوەیەکی خۆکار ناکرێت. پێش گۆڕینی فۆڵدەری ئەو وەشانە، سێرڤەر دابخە و `ZHIROX_DATA_DIR` بە ناونیشانی تەواوی داتای کۆن دیاری بکە. ئەگەر هەردوو شوێن داتا بگرن، سیستەم داوای دیاریکردنی ڕێڕەوی ڕوون دەکات و داتابەیسەکان یەک ناخات.

`npm run doctor` تەنها Node، SQLite ـی کاتی و نووسین لە فۆڵدەری داتا دەپشکنێت؛ فایلەکانی داتابەیس و ناسنامە ناگۆڕێت و پەیوەندی بە کلاود ناکات. [پاکێجی Windows](WINDOWS.md).
